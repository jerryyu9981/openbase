## 1. 目的与口径

### 1.1 目的

1. 把 R1~R7 收口后**仍然登记但未执行**的事项统一成一张台账，消除「文档里挂着、排期里没有」的盲区；
2. 把**跨仓未执行**（OpenLLM / OpenRAG / OpenMemory / DPS / 运维）与**本仓未执行**分开列账，明确责任方与前置条件；
3. 按依赖关系拆入**小版本迭代**（每个小版本 1~5 项、可独立验收、可独立回滚），避免再次出现大轮次混提交；
4. 明确「建设 / 收敛 / 冻结 / 不建设」四种处置，不再以 mock 填充。
