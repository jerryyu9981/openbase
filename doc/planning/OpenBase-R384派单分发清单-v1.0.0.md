## 2. 分发方式

| 项 | 说明 |
|----|------|
| 分发渠道 | 由用户在**各仓自身对话**中投递给对应仓（出具方无法跨会话投递） |
| 建议投递内容 | 对应单仓正文文件 + 一句话诉求："按 R-384 派单实施本仓 `request_id` 日志接线与 JSONL 结构化，完成后回执" |
| 执行边界 | 各仓**独立评审、独立提交、独立发布**；OpenBase 侧不代改他仓代码 |
| 沙箱外提交 | 各仓均已具备提交辅助脚本（`*_commit_push.ps1` / `*.bat`），可在沙箱外执行提交与推送 |
