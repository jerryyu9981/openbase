# DEF-BE-147-005 定位证据：`rag-proxy/collections` 400 响应体抓取与根因

- 抓取时间：2026-09-20 01:49~01:53（本地）/ 17:49~17:51Z
- 环境：五方服务以编排器启动（`-Action start -Only openrag,openbase`），OpenRAG M2（`OPENRAG_IDENTITY_TRUSTED_PROXY_SOURCES=["openbase-rag-proxy"]`）已启用
- 方法：① 经网关调用 ② 直连 OpenRAG 以「网关同构头」逐头增补消元 ③ 读 OpenRAG 源码定位 400 分支
- 结论：**根因 = OpenRAG M2 受信入站的「保留租户码碰撞」防护**（非格式问题、与角色无关）

## 3. 源码定位（OpenRAG `src/openrag/api/middleware/identity_gate.py`）

```python
# L224-239  _handle_trusted_identity()
values = validation["values"]
tenant_code = values.get(HEADER_TENANT_ID) or LOCAL_DEFAULT_TENANT_CODE   # ← 缺省即 "default"
# B2 碰撞防护：受信 X-Tenant-ID ∈ 保留码空间 → 400（保留码仅 M1 本地可用）
if is_reserved_tenant_code(tenant_code):
    return self._reject(code=BIZ_RESERVED_TENANT_CODE_COLLISION,
                        message="reserved tenant code is not allowed on trusted inbound",
                        status_code=400,
                        detail={"tenant_code": tenant_code,
                                "reserved_codes": sorted({"default", "openrag-local"})})
```

- M2（受信）路径下，未显式给出 `X-Tenant-ID` 时**缺省取 `LOCAL_DEFAULT_TENANT_CODE` = `default`**；
- `default`（以及 `openrag-local`）是 OpenRAG 的**本地保留租户码**，**禁止出现在受信入站**（防采集侧伪装本地租户）；
- 本仓网关注入的身份头含 `X-Tenant-ID: default`（联调演示租户码）→ 命中该防护 → **400 `BIZ_RESERVED_TENANT_CODE_COLLISION`**；
- 该分支的 `_reject(...)` 应产出带 `code/message/detail` 的错误体，但**实测响应体为空、且 OpenRAG 未记录拒绝原因**（`request_completed` 仅记状态码）→ 属独立可排障性缺陷，见 §4。

## 4. 派生的次级发现

| # | 发现 | 影响 |
|:-:|------|------|
| 1 | 400 拒绝响应**无响应体**（网关与上游均为空），且日志无拒绝原因 | 排障成本高（本次需靠逐头消元定位）；建议 OpenRAG 在 `_reject` 保证产出错误 envelope 并补 `identity_rejected` 审计日志 |
| 2 | 冲突本质是**租户码语义**：OpenBase 联调租户码 `default` 与 OpenRAG 本地保留码同名 | 需跨仓/设计层对齐（不宜单方在采侧绕过） |

| 方案 | 做法 | 代价 | 影响 |
