==================== 四、修正前后行为对照（F-08） ====================

修正前（进程内计数器 + INSERT OR IGNORE）：
  重启后计数器归零 → 同会话 seq 从 1 重新开始 → 与历史行 (session_id, seq, target)
  幂等命中 → submit 返回 False 且不执行 → 重启前 N 次回写静默丢弃
修正后（持久化来源 max_seq + 1）：
  重启后 seq = 落盘最大序号 + 1 → 无幂等命中 → 首次回写正常入队
  → 硬判据「重启后回写丢失数 = 0」成立（用例 test_no_silent_loss_after_restart 断言 submit is True）
