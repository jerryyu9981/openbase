==================== 四、契约对应 ====================

| D2 契约项 | 落点 | 用例 |
|-----------|------|:----:|
| 请求体字段 `session_id`，**可选** | `llm.ts` 两方法 payload 类型 + `session_id?: string` | ✅ |
| 同一会话多轮**复用同一标识** | `session.ts#getSessionId`（会话内稳定） | ✅ |
| 新建会话生成**新标识** | `session.ts#resetSessionId` | ✅ |
| 标识**不含凭据类信息** | 随机值（`crypto.randomUUID`），用例断言不含 bearer/token/secret/password/sk- | ✅ |
| 覆盖流式与非流式两条路径 | `sendChat`（stream:false）/ `sendChatStream`（stream:true） | ✅ |
| 显式传入时以传入值为准 | `withSessionId` 显式优先 | ✅ |

实现说明：
  - 载体为 `sessionStorage`（同一标签页会话内复用）；存储不可用（隐私模式 / 测试环境）时
    自动退化为内存值，**不抛错、不阻断发消息**；
  - 标识仅为随机值，**不做用户 / 租户 / 设备编码**（避免承载身份信息）；
  - 未改动 `http` 拦截器与鉴权链路。
