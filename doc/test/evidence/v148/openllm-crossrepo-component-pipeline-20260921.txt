==================== 三、共用范围与实现要点 ====================

共用步骤 `run_components(...)` 统一以下语义（两条路径同一实现）：

| 语义 | 说明 |
|------|------|
| 条目解析 | 兼容两种 pipeline 结构：同步 `name`+`params` / 流式 `component`+平铺键（`entry_key`） |
| 调度 | `enable_parallel` 且组件数 > 1 时 `asyncio.gather`；否则串行（§6.2 默认串行） |
| 组件级降级 | handler 未注册 / `ComponentUnavailableError` / `TimeoutError` / 未知异常 → degraded + errors，**不中断主流程** |
| RAG 回退 | 外部检索失败且启用回退 → 调注入的 `rag_fallback(params)`，`rag_source=builtin`；成功为 `external`；无 rag 组件为 `skipped` |
| 上下文格式化 | `assembler.format_context(name, data)` → `contexts["{name}_ctx"]` |
| 耗时 | 写入调用方 `timeline`：`{"step": name, "ms": int}`（覆盖降级路径，与流式原行为一致） |

依赖注入而非重复实现：适配器（流式）与 handler（同步）由各路径注入；两条路径不再各有一份
组件执行循环 → 消除 F-01 的第二个分叉点（第一个分叉点在批次 4 收敛为共用组装步骤）。

==================== 四、语义变更（必须知悉） ====================

**流式路径 RAG 适配器未注册的处理语义发生变化**：

| 场景 | 旧行为（流式私有实现） | 新行为（共用步骤） |
|------|------------------------|--------------------|
| `rag_adapter is None`（适配器未注册） | 抛出 `ComponentUnavailableError` → 被内层 `except Exception` 捕获 → **回退内置 RAG**（若启用） | 组件级**降级**（degraded 记录），**不触发回退** |
| 外部 RAG 检索失败（其他异常） | 回退内置 RAG（若启用） | 同上（**保持不变**） |

变更理由：适配器未注册属装配/配置缺陷，回退会把装配缺陷掩盖成「检索成功」；且同步路径从不因
「适配器未注册」回退，统一为降级后才与同步路径语义一致（AC-148-03-1 要求两路径行为一致）。
**回归结果：147 例全绿，无既有用例依赖旧语义。**
