## 2. 测试架构（T1-T4）

| 层级 | 名称 | 范围 | 通过标准 |
|:----:|:-----|:-----|:---------|
| T1 | 契约层 | 网关 API 契约 vs API 设计文档（路径/方法/请求/响应/错误码） | 路由映射 diff 无差异 |
| T2 | 接口层 | 网关 API 功能（注册/列表/下线/健康/聚合）+ 错误码 + 权限 | P0/P1 API 全通过（状态码+结构+边界） |
| T3 | 页面/集成层 | T3a 全页面巡检（27 路由可达 + 网络信号）+ T3b 深度用例（网关前端 CRUD） | 无阻塞问题 + L4 网络层断言通过 |
| T4 | 验收层 | 核心业务流走查（网关注册→健康→聚合；前端页面加载） | 走查全部通过 |
