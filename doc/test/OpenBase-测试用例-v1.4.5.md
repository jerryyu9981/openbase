## 2. 用例详述（关键用例）

### TT-145-002 身份头注入

| 项 | 内容 |
|----|------|
| 前置条件 | 登录获取 token（含 tenant_id/org_id/role）；或直签 JWT |
| 测试步骤 | 1) 带完整身份 JWT 请求 → 断言四头（X-User-ID=42/X-Tenant-ID=tenant-001/X-Org-ID=org-001/X-User-Role=admin）；2) 无身份 JWT 请求 → 断言 default 兜底（default-tenant/default-org/user） |
| 预期结果 | 四头注入正确；映射/兜底符合 API 设计 §2 |
| 三要素 | 状态码 200 + 请求头断言 + 边界（缺失字段兜底） |
| 证据 | pytest test_dps_proxy_identity_headers_injected + identity_defaults_when_missing |

### TT-145-005 {detail} 归一化

| 项 | 内容 |
|----|------|
| 前置条件 | 登录获取 token |
| 测试步骤 | 1) 404 {detail:"画像不存在"}；2) 500 {code:5000,message} |
| 预期结果 | 统一 {code,message,data:null,timestamp}；提取顺序 body.code > detail > HTTP 状态码 |
| 证据 | pytest test_dps_proxy_detail_error_normalization + gateway_error_passthrough |

### TT-145-008 集成链路

| 项 | 内容 |
|----|------|
| 前置条件 | OpenBase 8000 运行；DPS 未就绪（H 类） |
| 测试步骤 | 1) 登录 → 2) 画像列表（DPS 不可达 → 502）→ 3) 详情（502）→ 4) health（502） |
| 预期结果 | 全部 502 SYS_UPSTREAM_ERROR 归一化（上游不可达契约正确） |
| 断言 | L1（状态码 + 统一结构）+ 记录 H 类环境遗留 |
| 证据 | smoke_v145.py（11/11） |

### TT-145-010 E2E 核心流程

| 项 | 内容 |
|----|------|
| 前置条件 | 三服务运行（DPS 未就绪时页面显示错误态） |
| 测试步骤 | 1) 登录 → 2) 画像列表页（真实渲染：KPI/表格/错误态）→ 3) 画像详情页（加载/错误态） |
| 预期结果 | 页面无代码类 HTTP≥500 / requestfailed / console error（H 类 502 登记） |
| 断言 | L1（元素存在）+ L4（网络层） |
| 证据 | 浏览器走查 |
