## 4. 风险与假设

- 四系统对接挂起（VC-005）：前端契约 mock，不测真实四系统后端
- asyncpg Windows 崩溃（P2 环境）：全量 pytest 受限，测试以 proxy/settings 相关为准
- UAT 需人工执行（用户审批）
