## 1. 评估范围与方法

| 维度 | 做法 |
|------|------|
| **完整性** | 逐类核对需求类别（功能/非功能/数据/权限/UI/接口/约束/验收）是否齐备 |
| **可测性** | 逐条核对 P0/P1 需求的验收条件是否**可判定**（含验证方式） |
| **可追溯性** | 按 RT-ID 逐项核对「版本目标 → BL → 需求 → AC」四层链，**不接受悬空** |
| **一致性** | 与 Step 0 已批准范围逐项比对，识别**扩项/漏项/口径漂移** |
| **基线检查** | 核对基线版本、冻结规则、变更规则是否明确 |
| **产出物存在性** | `LS`／`Glob` 实测 ＋ 体积校验（**空文件视为不存在**） |
