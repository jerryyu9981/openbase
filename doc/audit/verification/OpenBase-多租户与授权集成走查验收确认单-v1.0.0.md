## 1. 验收对象与判据

### 1.1 验收对象

本次走查覆盖 **5 个系统 / 4 个下游仓**（OpenBase 本仓 + OpenLLM / OpenRAG / OpenMemory / DPS），验收对象为两条主线的**全部走查发现项**及其修复/裁定落地：

- **主线①** 权限管理与多租户授权走查：F1 / F2 / F3（共 3 项）。
- **主线②** 跨仓数据面租户隔离走查：D1~D20（高危 7 / 中危项 / 低危 2）+ 4 项「需裁定」（A/B/C/D）。
- **收尾处置**：低危修复（D5/D15）、余下未决项裁定（A 挂起 / B1 / C1 / D）、跨仓隔离走查 §6.6 遗留处置（②③④）。

### 1.2 验收判据（门槛）

| # | 判据 | 通过标准 |
|:-:|------|---------|
| P1 | **发现项闭环** | 走查发现的全部缺陷项**已修复**或**已按裁定落地**（含「登记·不翻转默认」的显式处置），无未处置项 |
