## 1. 验收对象与判据

### 1.1 验收对象

**主备双通道生产上线**放行验收：

- **主通道 B**：会话 → OpenBase `/api/v1/llm-proxy/chat`（四头注入）→ OpenLLM 编排（三路取数 + 上下文精装配）→ LLM → **三路回写**（memory / rag / profile）。
- **备通道 A**：OpenBase 不经编排**单独直连** DPS / OpenMemory / OpenRAG（降级读取；**不承载写**）。

### 1.2 验收判据（Go / No-Go 门槛）

| # | 判据 | 通过标准 |
|:-:|------|---------|
| **G1** | **三 REAL 开关置真** | 目标环境显式置 `OPENLLM_OPENRAG_REAL` / `OPENLLM_OPENMEMORY_REAL` / `OPENLLM_DPS_REAL`（+ `OPENMEMORY_ENABLED` / `DPS_ENABLED`）= `true`；运行态调用**真实契约端点**（非 stub）；`/health` 三组件 `ok` |
| **G2** | **生产门禁 5 组开关置真** | `ENV=production` 下应用正常启动（未置真按门禁拒绝启动）；启动日志无门禁告警 |
| **G3** | **L2-1 主备切换演练（真实）** | `B 断 → A 接管`（走 A 直连、写路径暂停）/ `A 断 → B 维持` 双场景留证 |
| **G4** | **L2-2 通道矩阵终验（真实）** | 每子系统 × A/B × 头语义矩阵逐行双签 + **写路径等价**（A 不写 / B 写）+ **K14 幂等** |
| **G5** | **回写链路真实面** | `POST /openllm/v1/writeback` 三路均落真实上游并留证；重复投递 `duplicated=true` 不重复执行；失败指数退避 ≤3 次 + 死信可视 |
| **G6** | **回写 `profile` 路由真实化** | `profile` 回写打到**真实 DPS**（非「Mock 先行」）；`extract_targets` 生效 |

> **Go 判定**：G1~G6 **全部通过**方可判定「准予上线」。
