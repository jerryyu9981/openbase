## 2. 缺陷清单与修复概览

| 缺陷 ID | 级别 | 类型 | 缺陷描述 | 根因 | 修复方案 | 修复 Commit |

| BUG-120-006 | P1 | F 类空实现 | 模型管理页"新增模型"按钮点击无任何反应，模型创建功能不可用 | `<el-button>` 无 `@click` 事件绑定，且无对应创建逻辑 | `Models.vue` 新增创建对话框（名称/Provider/类型）+ `createModel()` 校验函数（空值警告、成功后入列表并清空表单） | 9b0462f |
