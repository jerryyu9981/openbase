## 1. 版本目标（可衡量）

| # | 目标 | 量化成功指标 |
|:-:|------|--------------|
| 1 | **超窗归零**（P2 省 token；**硬判据**） | **超窗发生率 = 0** |
| 2 | **token 更省且不损精准**（P2 + P1） | 无效上下文占比（WCR）较 B1 **下降**，且人工走测评分**不低于** B1；预算利用率落入由 B1 数据回填的区间。**受 D3 约束**（无 B1 数据则本条记为「条件未满足」） |
| 3 | **选择可追溯** | 预算回执齐备（模型 / 窗口 / 输出预留 / 实际预算 / 裁剪前后 token / 被丢弃片段及原因 / 是否硬截断），覆盖率 **100%** |
| 4 | **写入不再自污染**（P3 回写） | `save_if_valuable=false` 时知识库不写入；知识库写入价值判定拦截率可观测 |
| 5 | **反馈闭环成立**（P3） | 回写携带本轮使用的上下文片段标识与得分；B2 / B3 基线报告产出（**受 D3 约束**） |

> **三项待定阈值的回填时点**：注入片段相关性下限（B1 后）、预算利用率区间（B2 后）、回写受理成功率（B3 后）。**数据源为 v1.4.8 的 B0 / B1**；若 D3 在 v1.4.9 开工前仍未确认，三项阈值按派单项 §7 过渡口径继续「先记录、不判定」，目标 2 的「评分不低于 B1」亦无法判定。

## 7. 版本发布策略草案

| 项 | 草案 |
|----|------|
| 版本类型 | 承接型小版本（1.4.x 承接线） |
| 发布方式 | main + tag `v1.4.9`，双远程（origin + backup，**非 `--mirror`**） |
| 兼容策略 | 裁剪由开关控制且**默认关闭**（保证与 v1.4.8 构建可比）；不改四系统对外接口 |
| 灰度 | 先开计量与回执（零风险）→ 再逐步开启裁剪（按租户或场景），观察评分与 WCR |
| 回滚 | 关闭裁剪开关即回退到不裁剪行为；第三批写入治理可单独回退 |
| 发布门禁 | ① 四件套（Backlog / Phase / 评审待补出）经人工批准；② **超窗率 = 0** 实测通过；③ 评分不低于 B1（D3 就绪时）；④ 三项阈值已回填或已按过渡口径声明；⑤ 本仓回归全通过 |
