## 1. 版本背景

v1.0.0（首个可用底座）已完成并发布（105 测试、覆盖率 90%、六模块落库、鉴权/RBAC/Redis 缓存）。v1.1.0 承接 v1.0.0 遗留事项与四系统回灌，实现"四系统整体运行在 openbase 底座上"的闭环。

## 2. 版本目标

| 目标 | 成功指标（可量化） |
|------|-------------------|
| 四系统回灌接入 openbase 底座 | 4/4 系统灰度接入通过（OpenLLM/OpenRAG/OpenMemory/DPS），对外接口与 MCP 工具清单不变 |
| 生产就绪 | Pro 环境部署上线检查通过；PyPI 发布 `pip install openbase` 可安装 |
| 运维完善 | OTLP 告警通道接入（P99>500ms/401 率>20% 告警可达）；模块独立版本管理 |
| 技术债偿还 | TD-001/002/004 全部偿还或部分偿还（还债占比 ≥15%） |

## 7. 版本发布策略草案

- 发布窗口：2026-10-13 ~ 2026-11-09（约 4-5 周，可弹性 ±1 周）
- 灰度：Dev（audit/otel）→ Test（auth/tenant/config/mcp）→ Pro（全量）
- 回滚：任一阶段失败 git revert，逐系统回滚
- 兼容：内核 API 向后兼容；破坏性变更需主版本
