## 1. 版本目标（可衡量）

| # | 目标 | 量化成功指标 |
|:-:|------|--------------|
| 1 | **DPS 模板化端点全量可达**（经 dps-proxy 代理，前端不直连 DPS） | dps-proxy 新增端点 **10/10** 可用；前端调用成功率 **100%**（联调实测） |
| 2 | **模板生命周期可视化闭环** | 页面与端点的**映射覆盖率 100%**（模板族列表/详情、版本对比、回滚、预检 5 类页面 ↔ 端点 1~5） |
| 3 | **标签血缘与影响面可查** | 反查与影响面返回真实数据（**非 mock**）；空谱系 → 404、未限范围 → 400 的语义**正确呈现**（不出现 500 / 白屏） |
| 4 | **AI 标注复核门禁在前端生效** | 默认关闭态**零写入**；未复核候选在前端提交 → 呈现 **409** 语义提示（与后端一致） |
| 5 | **隔离与鉴权口径不回退** | 跨租户/跨组织数据呈现为**空或 403**（无 500 / 无白屏）；身份头仍由 proxy 注入，**前端不可伪造** |
| 6 | **还债：DPS 模块 mock 页真实化** | TD-新增-006 中**归属 DPS 模块**的页面由 mock 改为真实 API 调用（页数与清单在 Backlog 细化时锁定） |

> 目标 3 / 4 的判据取自 DPS《API 接口设计文档-v2.11.0》v1.2.0 的错误码表与 §3.7 影响面口径（含偏差裁定 D-6-6「`field_key` 不支持 → 400」、D-6-7「非法标签 → 400」）；**不得**把上述 4xx 当异常处理。

### 2.2 不包含范围（未明确即不含）

1. **不含** DPS 后端任何改动 —— v2.10.0 / v2.11.0 已交付，本版本**只做对接侧**；若发现契约缺口，**不自行改 DPS 仓**（登记候选需求回 DPS 侧排期）
2. **不含** OpenLLM / OpenRAG / OpenMemory 模块的前端对接（各线另排）
3. **不含** v1.5「四系统统一集成测试 + 平台治理」任何已规划项
4. **不含** DPS 独立前端 `DPS/frontend/` 的任何改动（2026-09-10 起**已冻结**：保留不删、不再构建/发布、后端不挂载其产物）
5. **不含** DPS 侧 v2.9.0 GA 生产化 4 项（PG 主库路径验证 / 专用环境性能判定 / 可观测栈与告警 / 蓝绿·金丝雀演练，归 DPS 侧 **TD-3039**）
6. **不含** 模板编辑器高级交互（拖拽编排 / 富文本 / 可视化 schema 设计器）—— 首版仅**结构化表单 + JSON 视图**
7. **不含** 前端视觉规范与设计系统改动（沿用 S6 既定口径）

## 7. 版本发布策略草案

| 项 | 草案 |
|----|------|
| 版本类型 | 承接型小版本（1.4.x 承接线） |
| 发布方式 | main + tag `v1.4.10`，**三远程（origin ＋ backup ＋ github）**，以 `git ls-remote` 校验三处 hash 一致；**非 `--mirror`**（backup 仓含 `refs/remotes/*`，mirror 语义会删远端 ref） |
| 前端发布形态 | `openbase-ui` → **`dist-v1.4.10`** + nginx 同域 `/ui/` 静态 + `/api/` 反代（沿用 `openbase-ui/docs/frontend-frozen.md` §1 既定形态） |
| 兼容策略 | **不改 DPS 对外接口**；前端新增页面为**增量**，不破坏既有画像 2 页；proxy 新增端点为**新增路由**，不改既有 8 端点行为 |
| 灰度 | ① 先做 proxy 扩展（对前端零影响，可独立验证）→ ② 前端页面逐页上线（只读页先行：血缘 / 预检 / 措施建议 / 评分类型；写操作后行：导入 / 回滚 / AI 生成） |
| 回滚 | 前端回退上一版 `dist-*` 产物即可；proxy 新增端点可关闭而不影响既有 8 端点 |
| 发布门禁 | ① 四件套（Backlog / Phase / 评审**待补出**）经人工批准；② 10 端点联调全通；③ E2E 关键页 PASS + 隔离呈现回归通过；④ 覆盖率门禁达标；⑤ 4xx 语义契约用例全绿；⑥ 本仓回归全通过 |
