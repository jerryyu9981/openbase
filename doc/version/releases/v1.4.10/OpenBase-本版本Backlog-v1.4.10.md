## 2. 优先级评估记录（强制章节）

### 2.1 评估方法

采用**价值 / 成本 / 风险三维评估**＋**依赖前置优先**双规则：

1. **依赖前置优先**：阻塞其他条目的「前置零」条目无条件置 P0（无它则后续全部阻塞）；
2. **价值/成本/风险**：价值高、成本低、风险低者优先级高；含**写操作**或**权限门禁**的条目因风险上调一档关注度；
3. **门禁类条目置 P0**：质量门禁不达标即不得发布，按规范直接置 P0。

### 2.2 评估依据

| 依据 | 说明 |
|------|------|
| 能力兑现 | DPS v2.10.0／v2.11.0 模板化能力**已交付但统一前端不可用**（实测前端对接数 **0**、dps-proxy 白名单未暴露）⇒ 对接为价值兑现的唯一路径 |
| 契约完备 | DPS《API 接口设计文档-v2.11.0》v1.2.0 §2 给出 **10 端点清单**；§3.7 / §4 给出错误码表（含偏差裁定 D-6-6 / D-6-7）⇒ 契约风险可控 |
| 基线可复用 | v1.4.5 已交付 dps-proxy **8 端点** ＋ 四头身份注入 ＋ 前端画像 2 页真实化 ⇒ 本版为**增量深化**，非从零建设 |
| 债务同源 | TD-新增-006／007 的前端部分与本版 B 段**同源**（同属「代理链路的统一前端接入」）⇒ 还债与交付可同批施工 |
| 后端同源 | TD-新增-035／036 均改**本仓后端**（proxy / health / lifespan 面），与 A 段同文件面 ⇒ 不构成范围膨胀 |

### 2.3 评估结论

| 判定 | 条目 | 理由 |
|------|------|------|
| **P0（必须完成，否则不得发布）** | BL-01／02／03／04／11 | ① **BL-01 为前置零**（无 proxy 暴露则前端无数据源）；② BL-02／03／04 为模板化能力**入口与安全前提**（回滚为写操作，预检是回滚的安全前提，二者同批判定）；③ **BL-11 为发布门禁** |
| P1（本版目标内，可协商裁剪） | BL-05／06／07／08／10 | 具备明确用户价值但可后置；BL-10 为还债项且依赖 BL-01 |
| P2（有余量则做） | BL-09 | 只读列表，价值最低 |
| P3（低风险硬化，随版附带） | BL-12／13 | 与本版后端面同源的还债项；工作量小、风险低 |

> **P0 覆盖检查**：本版 **5 项 P0 全部有对应 BL 条目**（无 P0 项缺条目）✅
