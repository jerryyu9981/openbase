## 1. Phase 拆分

| Phase | 时间 | 内容 | BL 项 | 里程碑 | 验收重点 |
|-------|------|------|-------|--------|---------|
| P1 | 第 1 周 | 前端底座抽取与技术选型（四系统前端盘点/组件抽取/选型 ADR） | BL-201 | 技术选型通过 | 抽取清单 + ADR 记录 |
| P2 | 第 2-3 周 | 公共底座重新设计（布局/风格/路由/状态/组件库）+ 动态模块机制 + **响应式设计（栅格/断点/侧边栏折叠/表格横滚/图表自适应）** | BL-202, BL-203, BL-211 | 底座 v0 可用（三端适配） | 布局可运行 + 模块注册机制 + 三端无溢出 |
| P3 | 第 4-5 周 | 统一鉴权与 API 契约对接 + 对话监控模块 | BL-204, BL-205 | 对话监控可用 | 鉴权对接 + 契约对齐 0 缺口 |
| P4 | 第 6-7 周 | 知识库/记忆/画像模块 + 前端测试 | BL-206~209 | 4 模块全可用 | 测试 100% 通过、覆盖率 ≥80% |
| P5 | 第 8 周 | 部署与联调验收（Dev 环境 + 上线检查） | BL-210 | v1.2.0 发布 | 上线检查通过 |
