## 1. Phase 拆分

> 总原则（VC-005 调整）：**前端完整 + 基座调试完整 + 四系统对接挂起分批**——32 项功能前端全部补齐完整（四系统对接按契约 mock 先行）；基座（登录/鉴权/RBAC/动态模块/公共组件/公共页面）本次必须与 OpenBase 后端调试完整；四系统与后台接口对接调试挂起，后续按需分批。

| Phase | 时间 | 内容 | BL 项 | 里程碑 | 验收重点 |
|-------|------|------|-------|--------|---------|
| P1 | 第 1-2 周 | OpenLLM 模型中心补全 + 用户基础链路：提供商管理 CRUD、模型管理 CRUD+定价、本地模型、注册/找回密码、个人设置、用量统计 + **我的收藏 + 模型分类/对比（P1 高耦合）+ 代理层 402 错误码定义** | BL-301~306, BL-329~330, BL-328 | OpenLLM 模型中心可用 | 提供商/模型/本地模型 CRUD 完整；收藏/分类对比可用；402 统一错误响应可识别 |
| P2 | 第 3-4 周 | OpenLLM 对话与系统管理补全：对话管理（流式聊天/新建/归档）、监控仪表盘补全、API 密钥管理、告警管理、成本分析+预算、路由策略+熔断器 | BL-307~312 | OpenLLM 监控与系统管理可用 | 对话流式交互、密钥/告警/成本/路由页面真实实现 |
| P3 | 第 5-6 周 | **基座与后端调试完整（VC-005）：登录/鉴权/RBAC/动态模块/公共组件/公共页面与 OpenBase 后端联调 + 请求层代理封装（/api/v1/proxy/*）打通** | 基座调试（登录/鉴权/路由/动态模块） | 基座联调 100% 通过 | 登录/鉴权/RBAC/动态模块 E2E 通过；代理请求层封装可用 |
| P4 | 第 7-8 周 | OpenRAG 前端补全（对接挂起）：RAG 对话（流式 SSE + SourceTrace）、知识库列表（状态/进度/上传）、知识库详情（分块预览/ScoreBar）、用户管理、系统配置（按契约 mock） | BL-313~317 | OpenRAG 前端完整 | 页面交互完整；流式/来源追踪前端可用（mock 数据） |
| P5 | 第 9-10 周 | OpenMemory 前端补全（对接挂起）：记忆列表（添加/衰减权重/分页）、记忆详情（关联/统计/hard 删除）、知识图谱（D3）、会话管理 + **仪表盘（P1 高耦合）**（按契约 mock） | BL-318~321, BL-331 | OpenMemory 前端完整 | 记忆 CRUD + 图谱渲染 + 会话终止 + 仪表盘（mock 数据） |
| P6 | 第 11-12 周 | DPS 前端补全（对接挂起）：画像管理（六维雷达/风险）、标签管理（分类树/计算规则）、报表中心（指标/导出）、搜索分析（混合检索）、审计日志（筛选/导出）+ **数据总览（P1 高耦合）**（按契约 mock） | BL-322~326, BL-332 | DPS 前端完整 | 画像六维雷达 + 标签计算规则 + 混合检索 + 数据总览（mock 数据） |
| P7 | 第 13 周 | 全量回归测试 + E2E 走查 + 占位页清零核查 + 前端质量门禁 | BL-301~332 全部 | 质量门禁通过 | 30/30 P0/P1 前端可用；测试 100%、覆盖率 ≥80%、Lint 0、E2E 走查通过 |
| P8 | 第 14 周 | Dev 部署验收（基座联调验收）+ 前端完整交付报告归档 + 发布准备 | BL-301~332 + 基座调试 | v1.3.0 发布 | 基座联调验收通过；前端完整交付；四系统对接挂起清单归档 |
