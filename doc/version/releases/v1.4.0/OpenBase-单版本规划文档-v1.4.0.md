## 1. 背景与问题

| 项 | 内容 |
|----|------|
| 背景 | v1.3.0 覆盖 P0 26 项 + 高耦合 P1 4 项；差距分析报告 §8.2/§8.3 的剩余 P1 建议保留项与 P2 可延后项尚未排期 |
| 问题 | ①独立前端已验证的 P1 功能（高级管理/监控/工具）在统一前端仍缺失 ②P2 项（独立前端原型已有）未保留 ③生态工具链（i18n/测试基座/文档站点/示例项目）无明确排期 |
| 来源 | 用户业务输入"P0 必须补齐，P1、P2 等也都需要补齐"（VC-004）：v1.4.0 从远期转为明确排期 |

## 2. 版本目标

| 目标 | 描述 | 成功指标 |
|------|------|---------|
| G1 P1 全量补齐 | 差距分析报告 §8.2 剩余 P1 建议保留项全量实现（去占位/去缺失） | 剩余 P1 项 100% 可用；占位页清零 |
| G2 P2 保留 | 差距分析报告 §8.3 P2 项（独立前端原型已有）保留实现 | P2 项 4/4 可用 |
| G3 生态工具链 | i18n/测试基座/文档站点/示例项目交付 | 测试基座覆盖率门槛 ≥85%；i18n 覆盖全部页面；文档站点上线 |
| G4 质量门禁 | 前端测试与质量达标 | 测试 100%、覆盖率 ≥80%、Lint 0、E2E 走查通过 |
