## 1. 背景与问题

| 项 | 内容 |
|----|------|
| 背景 | v1.3.0 覆盖 P0 26 项 + 高耦合 P1 4 项；差距分析报告 §8.2/§8.3 的剩余 P1 建议保留项与 P2 可延后项尚未排期 |
| 问题 | ①独立前端已验证的 P1 功能（高级管理/监控/工具）在统一前端仍缺失 ②P2 项（独立前端原型已有）未保留 ③统一网关缺后端实例发现与聚合编排（ADR-13-04/05 已登记）；生态工具链（i18n/测试基座/文档站点/示例项目）经 VC-007 决策挂起，不在本版本交付 |
| 来源 | 用户业务输入"P0 必须补齐，P1、P2 等也都需要补齐"（VC-004）：v1.4.0 从远期转为明确排期；网关增强源自《网关服务发现与聚合编排技术方案》（ADR-网关-001/002）；生态工具链挂起（VC-007，用户决策"生态工具链先挂起，其他继续"） |

## 2. 版本目标

| 目标 | 描述 | 成功指标 |
|------|------|---------|
| G1 P1 全量补齐 | 差距分析报告 §8.2 剩余 P1 建议保留项全量实现（去占位/去缺失） | 剩余 P1 项 100% 可用；占位页清零 |
| G2 P2 保留 | 差距分析报告 §8.3 P2 项（独立前端原型已有）保留实现 | P2 项 4/4 可用 |
| G3 质量门禁 | 前端测试与质量达标 | 测试 100%、覆盖率 ≥80%、Lint 0、E2E 走查通过 |
| **G4 统一网关增强** | 后端实例发现（服务发现阶段一）+ 跨系统聚合编排（阶段一） | 实例健康感知 ≤30s；`/api/v1/services` 与 `/api/v1/gateway/aggregate` 可用；静态表兜底向后兼容 |

## 4. 技术债务评估

| 项 | 内容 |
|----|------|
| 本版本还债 | TD-004 示例项目原计划随生态工具链偿还，因生态挂起（VC-007）同步挂起；剩余技术债务按 v1.3.0 审计结论跟踪 |
| 还债占比 | 生态挂起后本版本无直接还债项，还债占比 <15%（以 Step 0 详细评估为准，需 PM 批准并记录于评审） |

## 5. 高层验收目标

| 项 | 标准 |
|----|------|
| P1 补齐 | 剩余 P1 项 100% 真实实现（经代理对接） |
| P2 保留 | 4/4 可用 |
| 质量 | 测试 100%、覆盖率 ≥80%、Lint 0、E2E 走查通过 |
| **网关** | 服务发现：实例注册/健康感知（scheduler 探测）/加权轮询/故障剔除通过；聚合：`/api/v1/gateway/aggregate` 并发聚合 2~3 子请求返回正确；静态表兜底与 `/api/v1/modules` 不受影响 |
| 部署 | Dev/Test/Pro 三环境验收 |

## 6. 关键风险与依赖

| 风险 | 级别 | 缓解 |
|------|------|------|
| R-401 高级功能依赖后端能力未开放 | P1 | 契约核对先行，缺口登记 v1.4.x 补 |
| R-403 独立前端 P1 页面实现质量参差 | P2 | 以核心交互对齐为准 |
| R-404 网关探测误判致流量抖动 | P1 | 连续 3 次失败才剔除 + 冷却期；探测与请求双通道 |
| R-405 网关能力与四系统对接批次（TD-006/007）并行 | P2 | gateway 仅改造 OpenBase 层，四系统零侵入；契约 mock 不受影响 |
| R-406 生态工具链挂起后测试基座缺失致覆盖率门槛降低 | P2 | 本版本仍执行测试 100%/覆盖率 ≥80%；测试基座门槛 ≥85% 随生态恢复后生效 |
