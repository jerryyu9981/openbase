## 2. Phase 明细

### 2.1 Phase 1 — 计量与工装就绪

| 维度 | 内容 |
|------|------|
| 目标 | 建立只观测不改行为的计量能力，并修正计量可信前置缺陷 |
| 范围 | BL-148-01（七项工装：Prompt 组成计量 / 检索快照 / 回执落库 / 归因 A / 归因 B 工具 / 固定集与评分表 / 汇总脚本）、BL-148-02（F-02 窗口前缀匹配修正）、BL-148-07 的 B0 部分（**受 D3 约束**） |
| 硬约束 | 工装**一律不得含裁剪、改写或截断逻辑**；本段不改变任何对话输出 |
| 交付物 | 工装代码 + 日期化模型名用例；**B0 基线报告（条件）** |
| 验收重点 | ① 计量字段可按 `request_id` 与会话标识批量导出；② 同输入前后对话输出一致；③ `gpt-4o-2024-08-06` → 128000 / `o200k_base`；④ B0 报告含方法 / 样本量 / 漏检率区间（D3 就绪时） |
| 依赖 | D3（B0 部分）、D1（跨仓排期） |
| 风险 | R2（D3 暂缓）、R4（工装污染基线） |

### 2.2 Phase 2 — 结构收敛与回写闭环

| 维度 | 内容 |
|------|------|
| 目标 | 消除双路径分叉，接通会话轴与三路回写，修正回写幂等键 |
| 范围 | BL-148-03（双路径收敛）、BL-148-04（会话轴接入）、BL-148-05（三路回写接齐）、BL-148-06（回写幂等键修正） |
| 建议顺序 | BL-148-06 → BL-148-03 → BL-148-05 → BL-148-04（先闭合 P1 数据丢失，再收敛结构，再接线，最后引入会话标识） |
| 交付物 | 共用步骤抽取、流式回写与缓存语义补齐、请求契约新增会话标识、三路回写回调与回执、幂等键改造 + 迁移说明 |
| 验收重点 | ① **重启后回写丢失数 = 0**（硬判据）；② 两路径行为一致（路由 / 注入片段集合 / 缓存命中）；③ 三路回写均产生记录且回执可查；④ 缺省无会话标识时仍按用户记账（兼容） |
| 依赖 | D1、D2（前端会话标识）、D4（既有队列数据迁移） |
| 风险 | R1、R3（流式回写可行性）、R5、R6 |

### 2.3 Phase 3 — 基线补齐与收口

| 维度 | 内容 |
|------|------|
| 目标 | 完成 B1 基线测量（**受 D3 约束**）与文档口径整合，完成版本收口 |
| 范围 | BL-148-07 的 B1 部分、BL-148-08（编排归属与 DSL 边界定界） |
| 交付物 | B1 基线报告（条件）；设计文档边界条款；版本收口材料（DevLogReport 等，属 Step 3/4 产出） |
| 验收重点 | ① B0→B1 差值可解释（D3 就绪时）；② 边界条款写入设计文档且无残留歧义；③ 硬判据与指标逐项给出实测值 |
| 依赖 | D3（B1 部分） |
| 风险 | R2 |

## 3. 里程碑

| 里程碑 | 判据 | 所属 Phase |
|:------:|------|:----------:|
| **M1 工装就绪** | 七项工装可用，计量字段可批量导出，且**未改变对话输出** | Phase 1 |
| **M2 B0 基线达成**（条件） | B0 报告产出（含方法 / 样本量 / 漏检率区间）；**受 D3 约束**，未就绪则记为「条件未满足」并保留测量入口 | Phase 1 |
| **M3 两路径行为一致** | 同输入两路径路由结果、注入片段集合、缓存命中一致 | Phase 2 |
| **M4 回写闭环且重启零丢写** | 三路回写均生效且回执可查；**重启后回写丢失数 = 0**（硬判据） | Phase 2 |
| **M5 版本交付** | 全部 P0 条目验收通过（条件条目按声明处理）；版本成功指标逐项给出实测值；收口材料齐备 | Phase 3 |
