## 1. 版本目标（可衡量）

| # | 目标 | 量化成功指标 |
|:-:|------|--------------|
| 1 | **回写闭环成立**（P3 回写） | 三路回写（记忆 / 知识库 / 画像）在**同步与流式两条路径**均生效；回写回执（受理状态 / 投递序号 / 被丢弃项）覆盖率 **100%** |
| 2 | **回写不丢**（P3；**硬判据**） | **重启后回写丢失数 = 0**（F-08 回归用例） |
| 3 | **会话轴成立**（P1 精准） | 多轮指代类问题能正确利用会话历史；四类素材（画像 / 记忆 / 知识库 / 历史）注入覆盖率 **100%**（不可用须留降级记录） |
| 4 | **结构前置就绪** | 同步与流式两路径同输入行为一致（路由结果、注入片段集合、缓存命中一致） |
| 5 | **基线可测（条件目标）** | 无条件部分：工装就绪（第零段交付）；F-02 修正后日期化模型名窗口取值正确（`gpt-4o-2024-08-06` → 128000 / `o200k_base`）。**条件部分：B0 与 B1 两份基线报告的产出以 D3 确认为前提**；D3 暂缓确认期间本目标记为「条件未满足」，不据此判定版本失败 |

> 目标 1~4 为无条件目标；目标 5 部分条件化（见 §4 D3 与 §5 R2）。

## 2. 版本范围

### 2.1 包含范围

| 段 | 内容 | Backlog |

## 3. 优先级评估

采用「价值 / 成本 / 风险」三维评估，排序依据：**P1+ 债务优先（数据完整性）> 结构前置 > 能力补齐 > 文档整合**。

| BL | 价值 | 成本 | 风险 | 优先级 | 排序理由 |
|----|:----:|:----:|:----:|:------:|----------|
| BL-148-06 | 高 | 低 | 低 | **P0** | 修复已实测复现的 P1 静默数据丢失（TD-新增-023），代码量小、无外部依赖 |
| BL-148-05 | 高 | 中 | 中 | **P0** | 闭合 P1 能力缺口（TD-新增-022）：当前三路回写一条未生效 |
| BL-148-03 | 高 | 中 | 中 | **P0** | 结构前置，不收敛则后续每项均需双份实现 |
| BL-148-04 | 高 | 中 | 中 | **P0** | 会话轴是「精准」与预算记账的前提 |
| BL-148-01 | 高 | 中 | 低 | **P0** | 无计量则三条原则均不可证伪；仅观测，改造面可控 |
| BL-148-02 | 中 | 低 | 低 | **P0** | 计量可信前置（窗口被低估 15.6 倍），不修则工装数据不可信 |
| BL-148-07 | 高 | 中 | **高** | **P0（条件）** | 受 D3 约束；价值高但可行性未确认 |
| BL-148-08 | 中 | 低 | 低 | P2 | 本仓文档整合，可先行，不阻塞跨仓 |

## 6. 版本成功指标说明

| 指标 | 目标 | 判定方式 | 依赖 |
|------|------|----------|:----:|
| 三路回写路径覆盖 | 同步 + 流式均生效 | 两路径各跑一次会话，断言三路回写记录产生 | 无 |
| 重启后回写丢失数 | **0**（硬判据） | 跨进程受控重启前后对比（复用 F-08 复现用例形态） | 无 |
| 四类素材注入覆盖率 | 100%（不可用须留降级记录） | 计量回执中四类分项是否齐备 | D3（计量需真实调用） |
| 两路径行为一致 | 路由结果 / 注入片段集合 / 缓存命中一致 | 同输入分别打两路径对比 | D3 |
| 日期化模型名窗口取值 | 128000 / `o200k_base` | 单测（F-02 回归用例） | 无 |
| B0 / B1 基线报告 | 产出含方法 / 样本量 / 漏检率区间 | 报告文件存在且要素齐备 | **D3（条件）** |

## 7. 版本发布策略草案

| 项 | 草案 |
|----|------|
| 版本类型 | 承接型小版本（1.4.x 承接线） |
| 发布方式 | main + tag `v1.4.8`，双远程（origin + backup，**非 `--mirror`**） |
| 兼容策略 | 新增字段一律可选，缺省保持既有行为；不改四系统对外接口 |
| 灰度 | 按段交付：第零段（只观测，零风险）→ 前置零 → 第一批；裁剪开关默认关闭（v1.4.9 才引入） |

| 发布门禁 | ① 四件套经人工批准；② 跨仓施工回执就绪；③ 本仓回归全通过；④ 硬判据（重启后回写丢失数 = 0）实测通过 |
