## 3. 关键交付物与接口契约

| 交付物 | 说明 |
|--------|------|
| OpenLLM 服务 | PORT=8001 启动，健康检查通过，与 OpenBase 8000 并存 |
| 认证适配 | OpenBase 侧 OpenLLM 认证通道（JWT/API Key 注入），对标 OpenMemory 双层认证共享模式 |
| llm-proxy | OpenBase 侧代理路由（模型列表/详情/对话核心端点），统一响应适配 {code,message,data,timestamp}，错误透传 + SSE 流式兼容 |
| OpenLLM 前端 | 模型管理/对话管理 2 页 mock/占位替换真实 API（走 proxy，前端不接触密钥） |
| 对接完善任务书 | 联调发现的 OpenLLM 侧占位/缺口登记（对标《OpenBase-OpenMemory对接完善任务书-v1.0.0》） |

| 指标 | 目标 |
