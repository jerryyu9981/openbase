## 1. 版本概述

### 1.1 版本定位

| 项 | 内容 |
|----|------|
| 版本主题 | 完整方案 A 类补足（认证汇聚点闭环 + 开发工具链 + 存储适配） |
| 版本类型 | 能力补足版本（增量） |
| 基线 | v1.4.0（Step 4 测试通过，Step 5 部署中） |
| 周期 | 2 周 |

### 1.2 背景与问题

| # | 问题 |
|---|------|
| ① | 统一网关已具备转发/服务发现/聚合，但"外部凭据统一进入"的服务级 API Key 认证缺失，认证汇聚点（完整方案 2.5）不完整 |
| ② | 四维身份上下文头（X-User-Id/X-Team-Id/X-Agent-Id）未承载，审计记录未绑定租户/用户（完整方案 2.7/2.9） |
| ③ | 开发工具链（openbase-cli/BaseCRUDRouter）未实现，影响后续版本开发效率（完整方案 3.3） |
| ④ | storage 仅本地后端，MinIO/S3 适配未接入（完整方案 3.2） |

### 1.3 版本目标

| 目标 ID | 目标 | 验收指标 |
|---------|------|---------|
| G1 | 服务 Key 认证闭环 | 签发/认证/吊销 API 可用；网关 /proxy 通道支持 Bearer Key；scope 校验生效 |
| G2 | 四维身份头承载 + 审计上下文 | 4 头解析依赖注入可用；审计记录含 tenant_id/user_id |
| G3 | 开发工具链 | openbase-cli 三子命令 + BaseCRUDRouter 可用 |
| G4 | 存储适配 | S3 兼容后端可选启用（本地回退） |
