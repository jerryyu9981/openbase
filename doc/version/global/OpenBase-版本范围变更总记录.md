## 2. 变更类型说明

| 类型 | 说明 |
|------|------|
| 新增 | 需求从候选池纳入某版本范围 |
| 移出 | 需求从某版本范围移出，回到候选池 |
| 替换 | 某需求被另一需求替代 |
| 延期 | 需求推迟到后续版本 |
| 合并 | 多个需求合并为一个 |
| 拆分 | 一个需求拆分为多个 |
