## 3. 回滚步骤

```
1. 停止 OpenBase 服务（uvicorn）
2. 代码回滚：git checkout v1.4.2（或 revert 850b2b6）
3. 配置回滚：移除 .env 的 OPENBASE_LLM_*（如回退 v1.4.2）
4. 重启 OpenBase 8000 → 健康检查
5. 验证：/health + /api/v1/auth/login（v1.4.2 基线功能）
6. OpenLLM 8001 停止（对接链移除，OpenMemory proxy 不受影响）
```
