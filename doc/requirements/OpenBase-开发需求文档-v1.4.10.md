## 2. 功能需求（FR）

### FR-1410-01 dps-proxy 扩展：DPS v2.11.0 新增端点代理暴露（BL-01，P0）

| 项 | 内容 |
|----|------|
| 输入 | 前端请求（经 `/api/v1/proxy/{system}/{path}` 或既有 dps-proxy 路由前缀） |
| 处理 | ① 复用 v1.4.5 既定**四头身份注入**（前端不可伪造）；② **权限动作映射**（导出/导入 → `portrait_template:create`；回滚 → `portrait_template:update`）；③ **隔离口径**沿用 v1.4.5；④ **4xx/5xx 错误体透传与映射**（与 DPS 契约逐字一致） |
| 输出 | 与 DPS 契约一致的响应体（成功与错误） |
| 状态 | 新增路由（**新增 10 ＋ 既有补代理 12 = 22**）；**既有 12 条路由行为不变**（TD-新增-038 口径校准） |
| 权限 | 由 proxy 侧按动作映射裁决；**前端不做判定** |
| 错误处理 | 400／403／404／409 **原样呈现语义**，不得转 500；5xx 保留上游语义与可诊断信息（**不含凭据**） |

### FR-1410-14 画像模板本体管理（BL-14，P0，D-1410-03 新增）

| 项 | 内容 |
|----|------|
| 输入 | 用户操作（列表筛选／详情查看／创建／更新／启停） |
| 处理 | ① **列表**：支持 `status`／`profile_type`／`subject_type` 过滤，返回 `{items,total}`；② **详情**：按 `code` 查询，不存在 → **404**；③ **创建**：校验失败 → **400（含字段级原因）**，`code` 冲突 → **409**；④ **更新**：**版本递增 ＋ history 留痕**；不存在 → 404、校验失败 → 400；⑤ **启停**：`activate`／`deactivate` **幂等**，不存在 → 404 |
| 输出 | 模板对象（含 `code`／`name`／`profile_type`／`extends`／`subject_type`／`version`／`status`／`dimension_config`／`attributes_schema`／`tag_bindings`／`evidence_policy`／`anomaly_rules`） |
| 权限 | 列表／详情 → `portrait_template:read`；创建 → `portrait_template:create`；更新／启停 → **`portrait_template:update`**（启停为 `POST` 但语义为**更新**，须走**端点级动作声明**，不得按方法默认判为 create） |
| 错误处理 | 400／403／404／409 **原样呈现**；**停用后新计算与新标注被拒**须在页面明示后果 |

### FR-1410-15 标注模板本体管理与字段体系（BL-15，P0，D-1410-03 新增）

| 项 | 内容 |
|----|------|
| 输入 | 用户操作（列表／详情／创建／更新／改挂／删除）＋ 字段定义 `field_schema` |
| 处理 | ① **列表**：支持 `template_code`／`scenario` 过滤；② **详情**：不存在 → 404；③ **创建**：`code` 已存在 → **409**，归属校验失败 → 400；④ **更新**：**可改 `template_code`（改挂）**，版本递增；⑤ **删除**：**存在关联标注数据 → 409 拒绝**，引用判定列缺失 → **fail-closed 409** |
| **字段体系口径** | `field_schema` 为**非空数组**，元素：`key`（必填、非空、**同模板内唯一**）、`type`（**仅 5 类**：`string`／`enum`／`number`／`date`／`list`）、`required`、`options`（`enum` 时**必填**）、`range`（`number` 时生效）、`target_dimension`（**有则参与标签联动**） |
| 输出 | 标注模板对象（含 `code`／`name`／`version`／`status`／`template_code`／`scenario`／`field_schema`） |
| 权限 | 列表／详情 → `annotation_template:read`；创建 → `annotation_template:create`；更新／改挂 → `annotation_template:update`；删除 → `annotation_template:delete` |
| 错误处理 | 400／403／404／409 原样呈现；**删除被拒的 409 须说明关联标注条数**（后端消息含条数） |

### FR-1410-16 归属与继承关系（BL-16，P0，D-1410-03 新增）

| 项 | 内容 |
|----|------|
| **归属（强归属）** | 标注模板 → 画像模板：`annotation_template.template_code` **非空、不可置空**；创建／改挂／标注提交**三处**校验「归属画像模板**存在且 `active`**」；标注模板自身须 `active` 方可被提交；基数 **1 画像模板 : N 标注模板**（按 `scenario` ＝ `intake`／`assess`／`check`／`general` 区分） |
| **继承（画像模板）** | `extends` 链：**不得自指**、**不得成环**、**深度 ≤2**、**父模板必须存在**；维度解析「**父先入 → 子覆盖同名 → 追加新维度**」；导出时**沿 `extends` 递归收集依赖**、写入顺序**父先子后**；**租户上下文下按租户过滤，不得继承他租户模板** |
| **解除语义（重要）** | 系统**不提供"解除归属"**：`template_code` 不可置空。解除只能通过 ①**改挂**到另一 `active` 画像模板，或 ②**删除标注模板**（有引用则 409）。UI **不得**提供"解除关联"按钮 |
| 权限 | 读关系 → 对应模板 `:read`；改挂 → `annotation_template:update`；删除 → `annotation_template:delete` |
| 错误处理 | 归属不匹配 → **400**（后端逐字语义，含期望/实际 `template_code`）；归属模板不存在／未激活 → **400**；删除被拒 → **409** |

### FR-1410-17 标签体系与标签联动口径（BL-17，P1，D-1410-03 新增）

| 项 | 内容 |
|----|------|
| **标签分类体系** | `tag_category` → `tag_value` **两层**结构（`tag_value.category_id` 外键）；分类 CRUD 由 **E-22（既有代理）** 承载，本版不改其行为 |
| **标签管理面** | `GET /portrait/labels`（**E-21**）当前**仅支持 `action=list`**，其余 `action` → **400** |
| **标注→标签联动口径** | 仅含 `target_dimension` 的标注字段参与联动；生成标签编码 **`tag_code = "{dimension}:{key}"`**；评分口径：`enum` 按选项**逆序**线性映射（首项 =100、末项 =0）、`number` 裁剪至 0~100、其他有值类型默认 **80**；**人工标注优先** |
| **明确排除** | **子标签／标签层级**：DPS `TagDefinition.parent_tag_code`（"父标签编码"）**仅存在于 Pydantic 模型**，`tag_definition` 建表语句**无该列** ⇒ 能力**未落库、不可用**。**本版不做**，转**跨仓需求**（见 §1.1 相邻说明与 D-1410-03 §3.4） |
| 权限 | 读 → `annotation_template:read`（标签管理面）／既有分类 CRUD 沿用原口径 |
