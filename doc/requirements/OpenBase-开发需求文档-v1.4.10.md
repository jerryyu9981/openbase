## 2. 功能需求（FR）

### FR-1410-01 dps-proxy 扩展：DPS v2.11.0 新增端点代理暴露（BL-01，P0）

| 项 | 内容 |
|----|------|
| 输入 | 前端请求（经 `/api/v1/proxy/{system}/{path}` 或既有 dps-proxy 路由前缀） |
| 处理 | ① 复用 v1.4.5 既定**四头身份注入**（前端不可伪造）；② **权限动作映射**（导出/导入 → `portrait_template:create`；回滚 → `portrait_template:update`）；③ **隔离口径**沿用 v1.4.5；④ **4xx/5xx 错误体透传与映射**（与 DPS 契约逐字一致） |
| 输出 | 与 DPS 契约一致的响应体（成功与错误） |
| 状态 | 新增路由；**既有 8 端点行为不变** |
| 权限 | 由 proxy 侧按动作映射裁决；**前端不做判定** |
| 错误处理 | 400／403／404／409 **原样呈现语义**，不得转 500；5xx 保留上游语义与可诊断信息（**不含凭据**） |

### FR-1410-02 模板族管理页（列表／详情／启停）（BL-02，P0）

输入：用户操作；处理：调用 E-01／E-02／E-03；输出：列表/详情/启停结果；权限：启停为写操作受 D4 口径约束；错误处理：空列表呈现空态（非报错），启停失败呈现后端语义。

### FR-1410-03 模板版本对比与回滚（BL-03，P0）

| 项 | 内容 |
|----|------|
| 输入 | 两个版本标识 |
| 处理 | 对比（E-04）→ 差异可视化 → 回滚（E-05）需**二次确认** |
| 权限 | 回滚需 `portrait_template:update`；无权限呈现 **403** |
| 错误处理 | 失败呈现后端语义；回滚后**必须做生效验证**（重新拉取详情比对） |

### FR-1410-04 模板预检 dry-run 与影响面（BL-04，P0）

输入：拟执行的模板变更；处理：调用 E-06（**不产生写入**）＋ E-07 影响面；输出：预检结论与影响面；错误处理：`field_key` 不支持 → **400 语义**。

### FR-1410-05 模板包导出／导入（BL-05，P1）

输入：导出范围／导入文件；处理：E-08／E-09；导入**必须支持 `dry_run`** 且与实做语义区分；错误处理：失败项**逐条呈现**。

### FR-1410-06 标签血缘反查与影响面（BL-06，P1）

输入：标签；处理：血缘反查 ＋ 影响面统计；输出：**真实数据（非 mock）**；错误处理：**无谱系 → 404**、非法 `field_key` → **400**。

### FR-1410-07 措施建议（只读）（BL-07，P1）

输入：模板族/标签；处理：拉取建议；输出：**原样呈现**（含后端免责声明，前端不删改）。

### FR-1410-08 AI 标注候选生成与复核门禁（BL-08，P1）

| 项 | 内容 |
|----|------|
| 输入 | 候选生成参数／复核决定（通过/驳回） |
| 处理 | 生成候选（可选）→ 复核 → 提交 |
| 权限 | 写操作受 D4 口径约束 |
| 错误处理 | **默认关闭态零写入**且呈现「**未启用**」（非报错）；**未复核提交 → 409 语义** |

### FR-1410-09 评分类型查看（BL-09，P2）

只读列表；空态呈现空列表（非报错）。

### FR-1410-10 DPS 模块 mock 真实化 ＋ 代理链路前端侧接入（BL-10，P1，还债）

范围**仅 DPS 模块**：本版新增/改造页面 **100% 真实 API**（代码检索无 mock 常量 ＋ 联调实测）；其余子系统页面**保持登记**。结项口径为 **TD-新增-006 部分偿还 ＋ TD-新增-007 DPS 线偿还**。

### FR-1410-11 质量门禁（BL-11，P0）

① 单测（vitest）；② E2E（playwright，portrait 关键页）；③ 覆盖率门禁（沿用 S6 口径）；④ **隔离呈现回归**（沿用 S6 基座）。**四类全绿方可发布**。

### FR-1410-12 日志硬化（BL-12，P3，还债）

① **非 Dev 环境关闭 `DEBUG`／`sqlalchemy.engine` echo**（环境模板默认）；② `/health` 增加指标摘要（RED 三要素）——**交出评估结论**（采纳与否均记完成）。

### FR-1410-13 首请求预热（BL-13，P3，还债）

将重初始化前移至 `lifespan`；交付**前后实测对比**证据。

## 3. 非功能需求（NFR）

| ID | 类别 | 要求 | 验证方式 |
|:--:|------|------|----------|
| **NFR-1410-01** | 性能（代理） | proxy 新增端点**不得引入可观测退化**：单端点热态 P95 ≤ 既有 proxy 端点同量级（基线参考 v1.4.9 热态 P50 37.5 ms／P95 71.2 ms，**仅作量级参照**） | 上线前抽样实测（≥30 次/端点） |
| **NFR-1410-02** | 性能（首请求） | 重启后**首请求延迟 ≤ 热态 P95 量级**（对比 v1.4.9 基线 2,150 ms） | 前后实测对比（60 轮抽样，记录最大样本） |
| **NFR-1410-03** | 安全 | 前端**零密钥接触**；身份头由 proxy 注入；**响应与日志零凭据** | 代码检索 ＋ 日志抽查 |
| **NFR-1410-04** | 安全（隔离） | 跨租户/跨组织 → **空或 403**，无 500／无白屏 | E2E 隔离回归 |
| **NFR-1410-05** | 兼容性 | **不改既有 8 端点行为**；新增页面为增量，不破坏既有画像 2 页 | 既有用例回归 |
| **NFR-1410-06** | 可用性 | 上游不可用时呈现**明确不可用**（非白屏）；**不静默降级** | 异常场景用例 |
| **NFR-1410-07** | 可维护性 | 页面↔端点**映射覆盖率 100%**（10 端点 ↔ 页面/组件可逐项对应） | 映射表核对 |
| **NFR-1410-08** | 可观测性 | 日志结构化（JSON）占比**较 v1.4.9 提升**（基线：JSON 4,394／27,084 行） | 日志统计 |
| **NFR-1410-09** | 测试性 | 覆盖率门禁达标（沿用 S6 口径）；E2E 关键页 PASS | 门禁脚本 |

## 4. 数据需求

| 项 | 内容 |
|----|------|
| **本版 DB schema 变更** | **无**（无 DDL/DML 迁移） |
| 数据实体（经 proxy 透传，不落本仓） | 模板族／模板版本／标签血缘／措施建议／评分类型／AI 标注候选 |
| 数据来源 | DPS 服务（经 dps-proxy） |
| 数据权限 | 由 DPS ＋ proxy 隔离口径约束；前端不做数据权限判定 |
| 生命周期与留存 | **本仓不落库**（透传）；导出模板包的落地位置与留存由用户环境决定 |
| 数据校验 | 契约级校验（端点参数与错误码）以 DPS 契约 v1.2.0 为准 |
