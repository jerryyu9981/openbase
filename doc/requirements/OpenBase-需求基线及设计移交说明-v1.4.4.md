## 3. 移交要点（给 Step 2 设计）

| 维度 | 内容 |
|------|------|
| 目标优先级 | P1 8 项（FR-144-01~05、07、09）+ P2 1 项（FR-144-08）；P1 必须全部满足验收标准 |
| 对接设计输入 | OpenRAG v1.8.0 现状（无 HTTP 认证、知识库/文档/查询端点、{code,message,data}+{detail} 双错误格式、SSE start/token/done、OPENRAG_API_PORT=8010、/api/v1/system/health、OpenAPI 无条件开放、v1.3 双前缀规避） |
| 复用设计输入 | v1.4.3 llm_proxy 模式（认证门禁/转发/响应适配/SSE 透传四函数拆分）——**差异**：无上游密钥注入（OpenRAG 无认证） |
| 配置设计输入 | settings 新增 rag_upstream_base=http://127.0.0.1:8010 / rag_upstream_timeout / rag_stream_timeout（.env 覆盖，OPENBASE_ 前缀） |
| 前端设计输入 | 知识库管理页/RAG 对话页 mock 替换真实 API（走 proxy）；文档上传异步轮询；SSE 流式渲染；沿用统一前端 Design Token |
| 质量要求 | 全量回归 ≥95%、覆盖率 ≥80%、Lint 0（ruff）；无新增 P0/P1 缺陷 |
| 风险提示 | OpenRAG 无认证（P1，JWT 门禁 + 任务书 M1）；8010 启动（P2）；错误格式不统一（P2 归一化）；文档异步（P2 轮询）；OQ-144-1/2 待联调闭环 |
