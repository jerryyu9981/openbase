## 1. 版本概述

### 1.1 背景

v1.2.0 统一前端已发布（底座 + 动态模块 + 四系统特色模块简化版），但经《OpenBase-统一前端与独立前端功能差距分析-v1.2.0.md》逐页核对，四系统独立前端已验证的功能大量缺失或仅占位（24 个占位页、14 个页面为本地 mock），保留率仅 15%~25%。本版本按"先补全、再对接"原则，将 P0 必须保留 26 项功能在统一前端真实实现，并全部经 openbase 代理 `/api/v1/proxy/{system}/*` 对接四系统真实 API。

### 1.2 版本目标映射（G1~G5）

| 目标 | 描述 | 成功指标 | 关联需求 |
|------|------|---------|---------|
| G1 P0 功能全保留 | 26 项全部真实实现（去 mock、去占位） | 26/26 项可用；占位页清零 | RT-301~326 |
| G2 四系统 API 对接 | 经代理对接真实 API | 4/4 系统联调通过 | RT-327 |
| G3 已验证功能平移 | 以独立前端为基线逐页平移 | 逐页对照差异 0 项 | RT-301~326 |
| G4 质量门禁 | 前端测试与质量达标 | 测试 100%、覆盖率 ≥80%、Lint 0、E2E 通过 | RT-301~328 |
| G5 技术债偿还 | 占位页/mock/代理链路/402 偿还 | TD-新增-006/007/008 关闭 | RT-327/328 |

### 1.3 业务目标与用户目标

| 类别 | 描述 |
|------|------|
| 业务目标 | 四系统核心业务功能在统一前端全量可用，消除"统一前端好看不可用"的现状 |
| 用户目标 | 管理员/运营人员通过统一入口完成模型、知识库、记忆、画像的全量管理操作，无需回到各独立前端 |
| 成功指标 | 统一前端替代独立前端的业务操作覆盖率 ≥80%（按 P0 操作数计） |
