## 3. 业务流程与业务规则（1.4）

### 3.1 主流程：模板治理（读→预检→写→验证）

```text
[开始] 进入 DPS 模块
  → 拉取模板族列表（GET 端点）
  → 选择模板族 → 拉取详情与版本列表
  → 选择两个版本做差异对比
  → 判定是否回滚 ── 否 → [结束]
                  └ 是 → 预检 dry-run（含影响面）
                         → 校验权限（proxy 侧映射 portrait_template:update）
                           ├ 无权限 → 呈现 403 → [结束]
                           └ 有权限 → 二次确认 → 执行回滚
                                      → 生效验证（重新拉取详情比对）
                                      → [结束]
```

### 3.2 分支流程：模板包导入

```text
[开始] 选择导入文件
  → 是否 dry-run ── 是 → 执行 dry-run → 展示校验结果 → [结束]
                  └ 否 → 权限校验（portrait_template:create）
                          ├ 无权限 → 403 → [结束]
                          └ 有权限 → 执行导入 → 展示结果（含失败项逐条）→ [结束]
```

### 3.3 分支流程：AI 标注候选复核

```text
[开始] 进入 AI 标注页
  → 能力是否启用? ── 否 → 呈现「未启用」（非报错）→ [结束]
                   └ 是 → 生成候选（可选）→ 逐条复核
                            ├ 驳回 → 标记驳回
                            └ 通过 → 提交（POST）
                                     ├ 未复核 → 后端 409 → 前端呈现 409 语义
                                     └ 已复核 → 写入成功
  → [结束]
```

### 3.4 失败流程与状态流转

| 失败点 | 触发 | 呈现要求 |
|--------|------|----------|
| 影响面 `field_key` 不支持 | 请求 400 | **显式 400 语义**（不得当异常） |
| 标签无谱系 | 请求 404 | **显式 404 语义** |
| AI 未复核提交 | 请求 409 | **显式 409 语义** |
| 跨租户/跨组织 | 隔离口径 | **空或 403**（无 500／无白屏） |
| 无写权限 | 权限拒绝 | **403**（前端仅呈现，不做判定） |
| DPS 不可用 | 上游故障 | 明确不可用提示 ＋ **不静默降级** |

### 3.5 业务规则

| 规则 ID | 规则 | 来源 |
|:-------:|------|------|
| BR-1410-01 | **前端不得直连 DPS**，一律经 dps-proxy；身份由 proxy 注入四头，前端**不可伪造** | 规划文档 §2.1-A |
| BR-1410-02 | **前端不做权限判定**，仅呈现后端/代理返回的 403 | R2 缓解 |
| BR-1410-03 | **4xx 为正常语义**（400／403／404／409），不得按异常处理 | R1 缓解（DPS 契约 §3.7／§4） |
| BR-1410-04 | **回滚为写操作**，必须「二次确认 ＋ 权限门禁」双约束 | BL-03 排序理由 |
| BR-1410-05 | **导入必须区分 `dry_run` 与实做**，语义不得混用 | BL-05 |
| BR-1410-06 | **AI 标注默认关闭 ⇒ 零写入**；关闭态呈现「未启用」而非报错 | BL-08 |
| BR-1410-07 | 措施建议**只读**，前端**原样呈现**后端免责声明 | BL-07 |
| BR-1410-08 | **不改 DPS 仓**；发现契约缺口登记候选需求回 DPS 侧排期 | 规划文档 §2.2 |
| BR-1410-09 | 本版**只收 DPS 模块范围内**页面 mock 真实化，其余子系统保持登记 | R3 缓解 |

**业务流程闭环性：主流程（3.1）＋ 分支（3.2／3.3）＋ 失败路径（3.4）＋ 规则（3.5）均已定义 ✅**
