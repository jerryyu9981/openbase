## 2. 页面与交互需求

### P-01 模板族管理
- **列表**：分页；列含模板族名称／状态／版本数／更新时间；空态呈现「暂无模板族」（非报错）。
- **详情**：展示基本信息与版本列表；提供「查看对比」「预检」入口。
- **启停**：**写操作** → 需确认弹层；无权限 → 呈现 **403** 提示（前端不做判定）。

### P-02 版本对比与回滚（**关键交互**）
- 对比：双版本选择 → 差异区（新增/修改/删除**分组呈现**）。
- **回滚二次确认**：弹层须同时呈现 ① 目标版本 ② **影响面摘要**（来自 E-07）③ 明确「不可撤销」提示 ④ 主按钮文案明确为「确认回滚」。
- **生效验证**：回滚成功后**自动刷新详情**并提示验证结果。

### P-03 预检 dry-run 与影响面
- **必须显式标注「预检（不写入）」**，避免用户误认为已执行。
- 影响面展示：受影响对象计数与清单；`field_key` 不支持 → 呈现 **400 语义**（"该字段键不受支持"），**不呈现 500／白屏**。

### P-04 导出／导入
- 导出：触发后提供**下载入口**（产物可下载）。
- 导入：**先选 dry-run 或实做**（**单一控件明确二选一**，不得默认实做）；dry-run 结果与实做结果**视觉可区分**；失败项**逐条列出**。

### P-05 血缘反查
- 输入标签 → 以关系视图或层级列表呈现血缘 ＋ 影响面统计。
- **无谱系 → 404 语义**（"未找到该标签的谱系"），不得呈现错误页。

### P-06 措施建议（只读）
- **原样呈现**后端文本（含免责声明）；**不得删改**；无建议 → 空态。

### P-07 评分类型（只读）
- 只读列表；空态正常呈现。

### P-08 AI 标注候选生成与复核
- **默认关闭** → 呈现「**该能力未启用**」状态 ＋ 说明文案（**非报错**）。
- 已启用：候选列表 → 逐条「通过／驳回」→ **提交前置检查**：存在未复核项时**阻止提交**并提示。**（D-1410-01 修订 v1.2.0）**错误码经 DPS **实现代码**核对后确认：**403**（AI 通道未启用）／**503**（适配器不可用，**降级不阻塞人工路径**）／**409**（**未复核候选进入标签/画像路径**，AI 复核门禁 DT-009，**保留**）；**复核提交复用 DPS 既有端点** `POST /portrait/annotations/{annotation_id}/review`；**复核辅助（LLM 判定/建议）由本仓 `llm_proxy` 转发 OpenLLM 提供**（A-1410-01 裁定）。
- **零写入约束**：关闭态下**不得发起任何写请求**。

## 4. 表单与校验要求

| 项 | 要求 |
|----|------|
| 版本选择（P-02） | 两端版本**不得相同**；相同则禁用提交并提示 |
| 回滚确认（P-02） | 二次确认**不可绕过**（不得提供一键直执行入口） |
| 导入模式（P-04） | dry-run／实做**必须显式选择**；默认值**不得为实做** |
| `field_key` 输入（P-03／P-05） | 前端做**基础非空校验**；**语义校验以后端为准**（不支持 → 400 呈现） |
| AI 复核（P-08） | 提交前**前端预检**未复核项（阻止提交）＋ 后端 409 兜底 |

## 5. 文案与提示口径

| 场景 | 文案口径（要点） |
|------|------------------|
| 400（字段键不支持） | 明确「不受支持」，给出可用字段键指引（若契约提供） |
| 403 | 「当前账号无权执行该操作」 |
| 404（无谱系） | 「未找到该标签的谱系」 |
| 409（未复核） | 「存在未复核的标注候选，请先完成复核」 |
| 未启用（AI 标注） | 「该能力当前未启用」＋ 联系管理员口径 |
| 上游不可用 | 「DPS 服务暂不可用」＋ 重试入口（**不静默降级**） |
| 回滚成功 | 「回滚已完成」＋ 生效验证结果 |

## 6. 无障碍与体验要求

| 项 | 要求 |
|----|------|
| 键盘可达 | 全部交互（含弹层确认）可键盘操作；弹层焦点陷阱正确 |
| 语义化 | 表格/表单使用语义标签；错误提示与字段关联（`aria-describedby`） |
| 对比度 | 沿用既有设计系统（**本版不改视觉规范**） |
| 动效 | 尊重 `prefers-reduced-motion` |
| 加载反馈 | 长耗时操作（导入/回滚）须有进行中状态 |
