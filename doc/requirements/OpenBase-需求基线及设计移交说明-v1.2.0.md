## 4. 风险与假设

| 项 | 内容 |
|----|------|
| 假设 | 四系统前端源码可访问且可抽取；四系统特色 API 可经 openbase 网关/代理对接 |
| 风险 | 四系统前端技术栈差异（抽取适配成本）→ Step 2 ADR 确认选型与适配策略 |
| 风险 | 特色 API 依赖四系统接口稳定性 → 联调阶段（RT-210）验证，失败降级为占位模块 |
| 风险 | 特色模块功能口径以四系统真实业务为准，接口面广（OpenLLM 52 路由页面/知识库 29 端点/记忆 50 端点/画像 52 端点）→ Step 2 按 OpenAPI 契约逐一收敛，超出 v1.2.0 范围部分登记 backlog |
| 风险 | AI 应用（应用管理/发布/市场）在 OpenLLM 中不存在，属统一前端全新补建 → Step 2 需单独设计数据模型与 API 契约，评估工作量 |
