## 3. 非功能需求

| NFR-ID | 类别 | 指标 |
|--------|------|------|
| NFR-11-01 | 性能 | 底座接口 P50 < 200ms；P99 < 1s；并发 50 |
| NFR-11-02 | 兼容性 | Python 3.11+；四系统对外接口不变（diff=0） |
| NFR-11-03 | 安全 | 密钥不入库；告警通道鉴权；回灌灰度最小权限 |
| NFR-11-04 | 可观测 | OTLP 指标/日志/追踪齐备；告警规则 ≥2 条生效 |
| NFR-11-05 | 可维护 | 模块独立版本；内核 API 冻结；AI 规则可执行 |
