## 3. 关键裁定

| # | 议题 | 裁定 |
|:-:|---|---|
| R1 | A7 关键字大小写与通配符 | 统一 `LOWER()`＋转义＋`ESCAPE`，不依赖数据库默认排序规则 |
| R2 | A1 `stats` 路由冲突 | DPS 与代理两侧静态段必须先于 `{annotation_id}`，各加顺序断言 |
| R3 | A2 `reviewer=me` 身份来源 | 仅服务端从 `X-User-ID` 解析；前端不得构造身份头 |
| R4 | A2 领取并发 | 不做跨库 `FOR UPDATE`；条件 UPDATE＋影响行数判定，冲突 409 |
| R5 | A2 权限动作 | `/claim` 声明为 `update`，并断言后缀唯一 |
| R6 | A5/A8/A13 | 不重复开发；以源码核对＋既有用例作为验证证据 |
