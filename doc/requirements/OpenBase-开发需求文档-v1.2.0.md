## 2. 功能需求

### 2.1 前端底座抽取（FR-12-01，P0，BL-201）

| 项 | 内容 |
|----|------|
| 用户故事 | 作为统一前端开发者，我需要从四系统前端抽取完整组件与布局，以便复用成熟实现 |
| 功能点 | ①四系统前端盘点（技术栈/组件/布局）②选型 ADR ③组件/布局抽取 |
| 验收标准 | AC-12-01：抽取清单 + ADR 记录完成；复用组件通过适配验证 |

## 3. 非功能需求

| NFR-ID | 类别 | 指标 |
|--------|------|------|
| NFR-12-01 | 性能 | 首屏加载 < 3s；路由切换 < 500ms；交互响应 < 200ms |
| NFR-12-02 | 兼容性 | 现代浏览器（Chrome/Edge/Firefox 最新 2 个版本）；分辨率 ≥ 320px |
| NFR-12-03 | 可维护 | 组件规范文档化；Lint 0 错误；模块独立可维护 |
| NFR-12-04 | 可访问性 | 关键操作键盘可达；对比度满足 WCAG AA |

## 4. 接口与集成需求

| ITF-ID | 接口 | 说明 |
|--------|------|------|
| ITF-12-01 | 前端 ↔ openbase 后端 | JWT 鉴权 + ErrorResponse 契约 + OpenAPI 生成（RT-204） |
| ITF-12-02 | 前端 ↔ 四系统特色 API | 对话监控/知识库/记忆/画像（经 openbase 网关/代理） |

## 5. 约束与排除项

| 项 | 内容 |
|----|------|
