### 2.5 OpenLLM 特色模块（FR-12-05，P0，BL-205，以 OpenLLM v2.9~v2.13 前端真实业务为准）

> 覆盖 OpenLLM 独立前端 5 组菜单（工作台/模型中心/AI 工具/路由与监控/系统管理，52 路由页面）中与 OpenBase 统一前端相关的核心业务域，含对话监控、大模型接入管理、AI 应用（全新补建）、路由与平台管理联动。

| 项 | 内容 |
|----|------|
| 用户故事 | 作为运维/运营/模型管理员，我需要完整的大模型接入管理、AI 应用与对话监控能力，以便统一管理模型接入、应用编排与运行监控 |
| 功能点 | ①大模型接入管理（模型中心）：模型管理列表（Tab 分类：全部/本地/开源/商业、关键词+高级筛选、状态：在线/离线/部署中/异常、新增/编辑弹窗、删除确认）、模型详情、本地模型管理（卡片网格、启动/停止/删除、Ollama 拉取新模型、运行时长/GPU 占用）、开源模型市场（搜索/分类/参数量、模型卡片、一键部署）、模型分类/模型对比/下载管理/我的收藏、提供商管理（卡片：类型标签/状态/支持模型数/延迟 P50、启用/禁用开关、详情抽屉：密钥脱敏/关联模型/健康状态）、提供商注册多步向导（Step1 类型：OpenAI/Azure/Ollama/Anthropic/自定义 → Step2 API 配置 → Step3 测试连接 → Step4 完成）、适配器管理（EdgeRouter：卡片网格/健康圆点/心跳/测试连接/注册/注销）、模型部署向导（选模型→配置并发数/超时/缓存→确认→部署日志流式输出）、GPU 资源监控（总数/已分配/空闲/故障、分配/释放、10s 轮询）、API 密钥管理（CRUD/权限范围/过期时间）②AI 应用（全新补建，OpenLLM 无此模块）：应用管理（创建/编辑/删除、模型绑定/Prompt 编排/参数配置）、应用发布（发布/下架、版本管理）、应用调用（API 调用记录查看）、Playground（模型对话调试、导出对话记录）、Prompt 模板管理（模板 CRUD/标签/变量占位符/模型关联）、Prompt 实验（变体配置/流量分配/评估指标/胜出设置）③对话监控：对话管理（列表：标题搜索/模型筛选/分页/多选、详情：完整内容+Token 消耗、流式对话 SSE：routing→chunk→done、JSON 导出、批量删除）、监控仪表盘（指标卡：QPS/平均延迟/P50/P99、请求量趋势、Provider 分布、时间范围 1h/6h/24h/7d/30d、10s 轮询）、用量统计（维度切换：模型/租户/时间、粒度：日/周/月、Token 趋势、用户排行 Top5、模型分布、报表导出 CSV/JSON）、服务健康与告警（服务卡片状态+P50/P99、适配器健康：健康/异常/离线/熔断、告警中心：待处理/已确认/已忽略、级别）、链路追踪（Trace ID 搜索、Span 瀑布图、Span 详情 Tags/Logs）、成本分析（成本趋势堆积图、明细表、导出）④路由与平台管理联动（经动态模块机制挂载）：路由策略（语义/级联/权重/A-B 测试、优先级、启停）、熔断器（OPEN/HALF_OPEN/CLOSED、失败阈值/半开超时/事件时间线/重置）、插件管理（列表/注册弹窗/启禁用/卸载）、配置中心（分类筛选/类型驱动编辑/变更历史/动态生效）、Webhook 管理（事件多选/请求头动态行/测试推送/HMAC 签名）、用户/角色/租户/配额管理（权限树、4 类配额卡：API 调用/Token/模型数/并发数、告警阈值滑块）、审计日志（过滤器/JSON 详情/导出）、计费概览（消费/趋势/额度） |
| 验收标准 | AC-12-05：①模型中心：模型/本地模型/提供商/API 密钥 CRUD 与状态展示通过，提供商注册向导（含测试连接）可用，模型部署向导验证 ②AI 应用：应用 CRUD/发布/调用记录验证通过，Playground 与 Prompt 模板/实验可用 ③对话监控：对话查询/详情/导出/批量删除可用，SSE 流式实时更新，监控指标（QPS/延迟 P50/P95/P99/错误率）渲染正确，维度/粒度切换与报表导出验证通过 ④联动项：路由策略/熔断器/插件/配置/Webhook/审计等经动态模块挂载验证，深度对接依赖四系统 API 部分登记 backlog |

## 3. 非功能需求

| NFR-ID | 类别 | 指标 |
|--------|------|------|
| NFR-12-01 | 性能 | 首屏加载 < 3s；路由切换 < 500ms；交互响应 < 200ms |
| NFR-12-02 | 兼容性 | 现代浏览器（Chrome/Edge/Firefox 最新 2 个版本）；分辨率 ≥ 320px |
| NFR-12-03 | 可维护 | 组件规范文档化；Lint 0 错误；模块独立可维护 |
| NFR-12-04 | 可访问性 | 关键操作键盘可达；对比度满足 WCAG AA |
