## 3. 设计阶段输入要点（Step 2 关注项）

| # | 输入要点 | 说明 |
|:-:|----------|------|
| 1 | **跨仓落点** | 主体在 OpenLLM 仓（第零段 / 前置零 / 第一批）；本仓仅 BL-148-08 文档整合与 BL-148-07 报告框架（`VC-014`） |
| 2 | **历史插入位置** | `assembler` 现顺序 System + 画像 + 记忆 + 知识库 + Query；历史插入位置**设计阶段定稿**（RT-148-04） |
| 3 | **会话标识契约** | `OpenLLMChatRequest` 新增可选字段；缺省退化为按用户记账（RT-148-04、R5） |
| 4 | **回写幂等键** | `(session_id, seq, target)` + DB 侧 `max_seq+1`；既有行保留 + 迁移说明（RT-148-06、R6） |
| 5 | **计量落点** | `routing_trace` 或独立表，设计阶段定稿；仅观测不改行为（RT-148-01） |
| 6 | **流式回写可行性** | R3 待前置核实；不可行须显式声明并写入契约（RT-148-03/05） |
| 7 | **边界条款** | 网关「聚合编排（BFF）」与 OpenLLM「pipeline 编排」边界写入设计文档（RT-148-08） |
| 8 | **验收依赖** | 硬判据（重启后回写丢失数 = 0）与 F-02 回归用例须在设计文档中预留测试形态 |
