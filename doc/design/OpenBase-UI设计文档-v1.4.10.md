### 1.1 设计一致性对齐（**强制基准**）

> 依用户要求：「原型设计必须保持和统一前端之前的设计风格一致，并在相关功能设计上，保持功能模块整体一致，并保持用户的易操作性」。

| 对齐维度 | **真实基准来源** | 原型落实（`prototype/proto.css` ＋ 9 页面） |
|----------|------------------|---------------------------------------------|
| **颜色 / 圆角 / 阴影 / 字体 / 断点** | `openbase-ui/src/core/styles/tokens.css` 的 `--ob-*` 变量 | **逐项照搬**（`--ob-primary #2563eb`／`--ob-bg #f8fafc`／`--ob-surface #ffffff`／`--ob-radius-sm·md·lg`／`--ob-shadow-sm·md·lg`／`--ob-breakpoint-lg 1280px`·`md 768px`）—— **不自造任何色值** |
| **组件视觉语言** | 项目组件库 **Element Plus** | 模拟 `el-card`／`el-table(stripe)`／`el-button(primary｜link｜danger)`／`el-tag`／`el-input`／`el-select`／`el-radio`／`el-dialog`／`el-drawer`／`el-alert`／`el-empty`／`el-descriptions`／`el-pagination`／`el-popconfirm` |
| **布局框架** | `core/layouts/AppLayout.vue` | `el-aside 220px`（折叠 64px）＋ `el-header 56px` ＋ `el-main`；侧栏菜单按「**业务模块**／**平台管理**」两级分组（与既有 Layout 同构） |
| **页面结构模式** | 既有 `modules/portrait/pages/DpsApiManageView.vue` 等 | `page-toolbar`（搜索 ＋ 主/次按钮）→ `el-card(header)` → `el-table stripe`（**操作列用 `link` 按钮**）→ 行内轻操作用 `el-popconfirm`（如「确认停用？」）→ 详情用 `el-drawer`、表单用 `el-dialog` |
| **空态文案句式** | 既有 `empty-text="暂无端点"` 模式 | 同句式：`暂无模板族`／`暂无措施建议`／`暂无已注册的评分类型` |
| **响应式** | tokens.css 三端断点 | `proto.css` §21 按 **≥1280／768–1279／<768** 同断点适配（移动端隐藏侧栏、表格横向滚动、触控目标 ≥44px 沿用 tokens 规则） |
| **无障碍** | 既有设计系统 | 语义表格/表单、错误与字段关联、折叠控件 `aria-expanded`、`prefers-reduced-motion` |

**模块归属与命名一致性**：本版 8 个页面**落点 `openbase-ui/src/modules/portrait/pages/`**（该模块既有 11 页，含 4 个 `Dps*View.vue` —— 与《权限限流API管理与监控归属裁定与收口方案》四项能力对应），**新增页面沿用 `Dps*View.vue` 命名风格**（如 `DpsTemplateListView.vue`／`DpsPackageView.vue`），**不新建模块、不改既有页面**。

**易操作性（用户视角）**：① 行内轻操作不跳页、不弹全屏；② 危险操作（回滚/导入实做）二次确认并携带影响面摘要；③ 结果区左右对照（预检 vs 实做）；④ 能力未启用**页顶第一时间可见**；⑤ `basis` 默认收起避免技术文本干扰主指标。

## 2. 页面布局与交互要点

| 页面 | 布局要点 | 关键交互 |
|------|----------|----------|
| **P-01** 模板族管理 | 左侧筛选 ＋ 右侧列表（分页）；详情**抽屉**（不跳页） | 启停 → **确认弹层**；无权限 → 呈现 403 |
| **P-02** 版本对比与回滚 | 上：双版本选择器；中：差异（新增/修改/删除**分组**）；下：操作区 | **回滚二次确认四要素**（目标版本／影响面摘要／不可撤销提示／主按钮文案「确认回滚」）；成功后**自动刷新并提示生效验证结果** |
| **P-03** 预检与影响面 | 上：**「预检（不写入）」横幅**（醒目）；中：校验结果；下：影响面三项 ＋ `basis` 折叠 | `field_key` 不支持 → **400 文案**；`tag_count=0` 时**强制展开**「未联动则为 0」口径 |
| **P-04** 包导出／导入 | Tab 切换导出／导入；导入区含**模式单选**（dry_run／实做） | **模式不得默认实做**；dry-run 与实做结果**视觉可区分**；失败项**逐条列出** |
| **P-05** 血缘反查 | 左：输入（`tag_code`）；右：血缘关系视图 ＋ 影响面 | 无谱系 → **404 文案**（非错误页）；`basis` 折叠；非法 `field_key` → 400 |
| **P-06** 措施建议 | 列表卡片（建议文本 ＋ 来源标签） | **原样呈现**（含 `disclaimer`，前端不改写） |
| **P-07** 评分类型 | 简单只读列表 | 空态正常呈现 |
| **P-08** AI 标注候选与复核 | 上：能力状态区（启用/未启用）；中：候选列表（逐条 通过/驳回）；下：提交区 | **关闭态零写入**；**复核辅助**按钮调 `llm_proxy`（来源标注）；提交走 DPS review；**未复核进入下游 → 409 文案**；503 → 「适配器暂不可用」**不阻断人工** |
| **P-09** 画像模板新建／编辑（**D-1410-03 新增**） | 表单式：基本信息（`code`／`name`／`profile_type`／`subject_type`／`status`／`description`）＋ **`extends` 继承选择**＋ 配置块（`dimension_config`／`attributes_schema`／`tag_bindings`／`evidence_policy`／`anomaly_rules`，**JSON 原样编辑不假设结构**） | `code` 冲突 → **409**（提示改名）；字段级校验失败 → **400 逐条呈现**；**`extends` 禁自环／禁成环／深度 ≤2／父须存在 —— 前端做即时提示但以服务端 400 为准**；保存后**版本递增提示** |
| **P-10** 标注模板管理（**D-1410-03 新增**） | 左：筛选（`template_code`／`scenario`）＋ 列表；右：详情**抽屉**（含 `field_schema` 只读表 ＋ `template_code` 归属链接） | 新建 → 进入 P-11 字段编辑；**删除 → 二次确认**；**删除被拒 → 409 且明确显示「存在 N 条关联标注数据」**；`scenario` 仅 4 选项 |
| **P-11** 标注模板字段与归属（**D-1410-03 新增**） | 上：**归属区**（当前归属画像模板 ＋ **改挂**选择器，候选项**仅 `active` 画像模板**）；下：**`field_schema` 字段编辑器**（字段行：`key`／`type`（5 类）／`required`／`options`（enum 必填）／`range`（number）／**`target_dimension`**） | **不提供"解除归属"按钮**（语义上不存在，**只能改挂**）；`key` 重复／enum 缺 `options`／未知字段 → **400 文案**；**改挂时提示"变更后新标注将按新归属校验"** |
| **P-12** 标签体系查看（**D-1410-03 新增**） | 上：**分类 → 标签值两层**结构（左分类列表，右标签值列表）；下：**标签联动口径说明**（`tag_code = "{dimension}:{key}"` 与评分规则） | **只读**（不提供编辑；分类 CRUD 由既有 `/tags/categories` 面承载，本页不复制）；`action=list` 之外不暴露 |

## 4. 关键交互规范

### 4.1 回滚二次确认（P-02，**强制四要素**）

```text
┌─ 确认回滚 ────────────────────────────────┐
│ ① 目标版本：v1（当前 v3）                  │
│ ② 影响面摘要：受影响标注模板 2／标注 12／标签 8  ← 来自 preflight，含 basis 折叠 │
│ ③ ⚠ 该操作不可撤销                        │
│ ④ [取消]            [确认回滚]（主按钮）   │
└───────────────────────────────────────────┘
```

**禁止**：提供绕过确认的一键直执行入口。

### 4.2 `basis` 折叠控件（ADR-06）

| 项 | 规范 |
|----|------|
| 默认态 | **收起**（仅显示三项指标） |
| 展开控件 | 「口径」文字按钮 ＋ 图标；`aria-expanded` 正确维护 |
| 内容 | `basis` 三段口径说明**原文呈现** |
| **强制展开场景** | `tag_count = 0`（避免误判为缺陷）；审计导出时**提供完整原文** |
| 键盘 | Tab 可达，Enter／Space 切换 |

### 4.3 导入模式（P-04）

| 项 | 规范 |
|----|------|
| 控件 | **单选（radio）**，不提供"默认实做" |
| 默认值 | **`dry_run`（预检）** |
| 结果区分 | dry-run 结果带「预检」标签；实做结果带「已执行」标签，**颜色/图标可区分** |

### 4.4 未启用与降级（P-08）

| 场景 | 呈现 |
|------|------|
| 能力关闭（403） | 「该能力当前未启用」＋ 说明（**非报错样式**） |
| 适配器不可用（503） | 「AI 适配器暂不可用」＋ **「人工路径不受影响」** 提示 |
| `llm_proxy` 不可用 | 「复核辅助暂不可用」＋ **复核提交仍可进行** |
| 未复核进入下游（409） | 「存在未复核候选，不得进入标签/画像路径」 |

---

### 4.5 归属与继承交互规范（P-09／P-11，**D-1410-03 新增**）

| # | 规范 | 理由（上游语义） |
|:-:|------|------------------|
| 1 | **不得提供"解除归属"按钮** | `annotation_template.template_code` **非空且不可置空** ⇒ 系统无"解除"语义；唯一路径是**改挂**或**删除** |
| 2 | 改挂选择器**候选项仅列 `active` 画像模板** | 上游要求归属模板**存在且 `active`**；列非 active 项会让用户必然踩 400 |
| 3 | 改挂前**明示后果**：「变更后新标注将按新归属校验」 | 归属为**强约束**（创建／改挂／标注提交三处校验） |
| 4 | `extends` 选择器**排除自身与已构成环的候选**，并**提示深度上限 2** | 上游硬约束：禁自指／禁环／深度 ≤2／父须存在；**前端仅做提示，最终以服务端 400 为准**（前端不做业务判定，BR-1410-02） |
| 5 | 继承关系**只读呈现**：详情中展示 `extends` 链（≤2 层） | 便于运维判断"改父模板会影响哪些子模板" |
| 6 | **`tag_bindings` 等 JSON 配置块原样编辑／呈现**，前端**不解析其内部结构** | DPS 侧对 `tag_bindings` **无结构与校验**（仅透传落库）；前端假设结构即为臆造 |
| 7 | 标注字段行中 `type=enum` 时 **`options` 必填校验前置**（未填即禁用保存并提示） | 上游 `field_schema` 校验硬规则 |
| 8 | 删除被拒时**必须显示关联条数**「存在 N 条关联标注数据」 | 上游 409 消息含条数；展示条数才能让用户判断如何处置 |
