归属约束三处生效：①创建 ②改挂 ③标注提交（归属不匹配 → 400，消息含期望/实际 template_code）。

联动口径：仅含 target_dimension 的字段参与标签联动，生成 tag_code = 「{dimension}:{key}」；评分 enum 逆序（首项 100／末项 0）、number 裁剪 0~100、其他默认 80；人工标注优先。
本页状态与易操作性说明（P-11）
  • 覆盖状态：加载态／表单提交态／成功态（版本递增）／归属约束态（归属模板未 active → 400）／错误态 400（key 重复、enum 缺 options、未知字段、范围越界）／权限态 403。
  • 归属：无「解除归属」按钮；改挂候选项仅 active；改挂前明示后果。
  • 易操作性：enum 未填 options 时行内高亮并禁用保存；target_dimension 留空即以灰字标注「不参与标签联动」。
  • 禁则：不假设 tag_bindings／上游 JSON 结构；前端不判权限。
