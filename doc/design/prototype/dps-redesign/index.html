一、原型地图

信息架构先看

四分组导航（概览 / 标注作业 / 模板与口径 / 标签与画像）、22 条路由处置、旧链接兼容策略。
01 今日工作台P0

待标注 / 待审核 / 返修 / AI 待复核四类待办；治理告警可直达修复。
02 标注作业台P0

队列 + 主体 + 表单/上下文三栏；领取任务、上一条/下一条、快捷键、暂存。
03 审核收件箱P0

多级审核、提交与当前画像对照、批量通过/驳回、审计时间线。
04 模板中心P1

健康度总览；模板详情抽屉聚合血缘 / 标注 / 评分 / 版本 / 预检。
05 模板工作台P1

步骤条 + 问题清单 + 发布向导（校验 → 口径 → 影响面 → 激活）。
06 标注模板与字段P1

字段设计器 + 实时表单预览 + 目标维度映射提示 + 归属改派影响面。
07 标签与口径P2

标签树 + 标签详情 + 血缘链路 + 口径体检问题直达修复。
08 画像与措施P2

列表列设置/批量/导出；360 标签分组与血缘抽屉；措施建议卡片化。
评审关注点
  • 信息架构：四分组是否符合日常动线？「审核收件箱」用同路由视图切换是否可接受？
  • 标注作业台：三栏宽度比例、主体选择器、快捷键集合是否符合标注员习惯？
  • 审核：提交值 / 当前值对照是否足够？批量通过的边界（仅 pending、仅末级联动）是否认可？
  • 模板治理：健康度口径、发布向导步骤、问题清单位置是否合理？
  • 兼容：旧路径全部保留，仅导航重排；是否允许后续为聚合视图新增查询参数？
