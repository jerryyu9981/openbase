三、v1.4.3 OpenLLM 对接 · 2 页真实化（FR-143-05/06，R-379）

v1.4.3 为 OpenLLM 系统对接（1.4.x 逐个系统对接线第 1 站）：模型管理/对话管理 2 页 mock 替换为真实 API（走 OpenBase llm-proxy，前端零密钥接触）。设计依据《OpenBase-UI设计文档-v1.4.3》《OpenBase-API接口设计文档-v1.4.3》《OpenBase-第三方集成设计文档-v1.4.3》。

模型管理页 /openllm/models P1

GET /api/v1/llm-proxy/models 真实数据（名称/Provider/类型/能力/定价/状态）；详情走 models/{id}；写操作按 OpenLLM 能力适配（默认禁用，缺口登记任务书）。

状态：空态 / 加载 / 错误 / 成功
交互要点
  • 加载态：表格 loading + 搜索防抖
  • 错误态：请求失败提示 + 重试
  • 空态：el-empty「暂无数据」

对话管理页 /openllm/conversations P1

GET /api/v1/llm-proxy/conversations 真实会话数据；新建/归档/删除映射会话端点；聊天视图内嵌 SSE 流式对话（routing→chunk→done 增量渲染）。

状态：空态 / 加载 / 错误 / 流式
交互要点
  • 流式态：输入禁用 + 增量渲染 + 停止按钮
  • 流中断：错误提示 + 重试
  • 表单提交态：按钮 loading 禁用

llm-proxy API 契约（12 端点） P1

/api/v1/llm-proxy/models · chat · chat/stream(SSE) · health · conversations*（OpenBase JWT；内层注入 Bearer sk-openllm-）。

契约：统一 {code,message,data,timestamp} · SSE 逐事件透传
