跨页关键交互（统一规范）
  • 回滚二次确认四要素（P-02）：目标版本 ／ 影响面摘要（含 basis）／ 不可撤销提示 ／ 主按钮「确认回滚」——禁止一键直执行。
  • basis 折叠（P-03／P-05）：默认收起，点「口径」展开；tag_count = 0 时强制展开；aria-expanded 正确维护。
  • 导入模式（P-04）：单选，默认 dry_run；预检与实做结果视觉可区分。
  • 未启用与降级（P-08）：403 未启用（非报错样式）／503 适配器不可用（人工路径不受影响）／409 未复核不得进入标签·画像路径。
  • 不静默降级（全部）：5xx 或上游不可用 → 明确提示 ＋ 重试入口。
  • 前端不做权限判定（全部）：仅呈现后端 403。
