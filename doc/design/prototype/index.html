OpenBase 统一前端 · 设计总览

版本 v1.2.0 · 四系统统一入口 · 动态模块架构 · 响应式三端（≥1280 / 768-1280 / <768）

Vue 3 + TypeScript + Vite + Element Plus + Pinia + ECharts
使用说明：本页为设计阶段原型总览首页（file:// 可直接打开）。页面按模块分组列出全部设计页面、优先级与核心交互；点击"交互要点"可展开设计细节。Step 3 实现对照本页与《前端架构设计文档 v1.2.0》《UI 设计文档 v1.2.0》执行；Step 4 E2E 断言以"交互状态清单"为基线。

一、公共底座（RT-202 / RT-204）

登录 /auth/login P0

账号密码 + JWT 登录，表单校验，错误契约映射（AUTH-XXX）。

状态：加载 / 错误 / 提交 / 成功
交互要点
  • 登录成功 → 跳仪表盘；401 → 提示密码错误
  • 响应式：表单居中全宽，无横向溢出

仪表盘 /dashboard P0

统一入口总览：今日/本月 Token、活跃模型数、模块快捷入口、最近活动。

状态：空态 / 加载 / 错误

系统管理 /system/* P1

用户/角色/租户/配置/审计日志（公共能力上移底座，从四系统抽取权限树）。

状态：空态 / 加载 / 提交

二、OpenLLM 特色模块（RT-205 · 板块重设计）

板块按业务域重组：模型中心 / AI 应用 / 对话监控 / 平台联动（公共能力已上移底座；AI 应用为全新补建）。

▍模型中心（大模型接入管理）

模型列表 /openllm/models P0

Tab 分类（全部/本地/开源/商业）、搜索筛选、状态（在线/离线/部署中/异常）、新增编辑弹窗、删除确认。

状态：空态 / 加载 / 提交

本地模型 /openllm/models/local P0

卡片网格、启动/停止/删除、Ollama 拉取、运行时长/GPU 占用。

开源模型市场 /openllm/models/market P1

搜索/分类/参数量、模型卡片、一键部署。

提供商管理 /openllm/providers P0

卡片（类型/状态/模型数/延迟 P50）、启禁用、详情抽屉（密钥脱敏/健康）。

提供商注册向导 /openllm/providers/register P0

多步向导：类型→API 配置→测试连接→完成。

API 密钥 /openllm/api-keys P1

CRUD/权限范围/过期时间。

模型部署向导 /openllm/deploy P1

选模型→并发/超时/缓存→确认→部署日志流式输出。

GPU 资源 /openllm/gpu P1

统计卡（总数/已分配/空闲/故障）、分配/释放、10s 轮询。

EdgeRouter 适配器 /openllm/adapters P1

卡片网格、健康圆点、心跳、测试连接、注册/注销。

▍AI 应用（全新补建）

应用管理 /openllm/apps P0

应用 CRUD、模型绑定/Prompt 编排/参数配置、发布/下架、版本管理。

状态：空态 / 提交

应用详情 /openllm/apps/:id P0

配置编辑、版本列表、发布历史。

调用记录 /openllm/apps/calls P1

分页/筛选/Token 与延迟统计。

Playground /openllm/playground P0

模型对话调试（流式 SSE）、导出对话记录。

Prompt 模板 /openllm/prompt-templates P1

模板 CRUD、标签/变量占位符、模型关联。

Prompt 实验 /openllm/prompt-experiments P1

变体/流量分配/评估指标/胜出设置。

▍对话监控

对话管理 /openllm/conversations P0

列表（搜索/筛选/分页/多选）、详情（Token 消耗）、JSON 导出、批量删除。

监控仪表盘 /openllm/monitoring P0

指标卡（QPS/平均延迟/P50/P99）、趋势图、Provider 分布、时间范围、10s 轮询。

链路追踪 /openllm/monitoring/traces P1

Trace 搜索、Span 瀑布图、详情 Tags/Logs。

成本分析 /openllm/monitoring/costs P1

堆积柱状图、明细表、导出。

预算管理 /openllm/monitoring/budgets P1

列表、告警阈值 80/90/100%。

告警中心 /openllm/monitoring/alerts P1

级别、单条/批量确认。

▍平台联动（经动态模块挂载）

路由策略 /openllm/routing/strategies P1

策略列表（语义/级联/权重/A-B）、优先级、启停。

熔断器 /openllm/routing/circuit-breakers P1

环形状态卡（OPEN/HALF_OPEN/CLOSED）、失败阈值/超时、事件时间线、重置。

三、知识库模块（RT-206 · OpenRAG 特色）

知识库列表 /knowledge P1

卡片/表格视图切换、统计条、创建/编辑、删除确认（级联）。

状态：空态 / 加载

知识库详情 /knowledge/:id P1

概览 hero（状态/文档数/嵌入数）、文档管理（上传/状态过滤/多选/重新索引）、分块预览、检索测试台（Agent 模式/来源追溯/评分）。

文档状态机展示 P1

pending→parsing→chunking→embedding→indexing→completed/error，轮询进度。

四、记忆模块（RT-207 · OpenMemory 特色）

记忆列表 /memory P1

分页/排序/类型筛选、衰减权重列（≥0.80 绿/0.50~0.79 黄/<0.50 红）、批量删除。

记忆详情 /memory/:id P1

完整内容+元数据、关联记忆跳转、WaypointTimeline（create/access/update/recall）。

记忆搜索 /memory/search P1

关键词+类型+时间范围、高亮、超时提示。

会话管理 /memory/sessions P1

列表（用户/IP/过期/记忆条数）、终止/批量终止、30s 刷新。

记忆图谱 /memory/graph P1

力导向图（实体/关系）、搜索过滤。

衰减配置 /memory/decay P1

策略（adaptive/time_only/none）、衰减因子、半衰期（默认 30 天）。

记忆写入 /memory/write P1

写入表单（memory_type）、多模态上传（图像/音频转录）。

五、画像模块（RT-208 · DPS 特色）

画像列表 /portrait P1

分页/搜索/排序、状态筛选与流转（active/inactive/archived）。

画像详情 /portrait/:id P1

基本信息、标签维护（打标/移除）、数据源。

画像搜索 /portrait/search P1

关键词+标签组合（AND/OR）、分数/时间范围、模糊搜索、自动补全。

标签管理 /portrait/tags P1

分类 CRUD + 值 CRUD + 标签统计。

分析报表 /portrait/reports P1

总览/维度分布/标签数量/趋势/组织分布/导出。

批量任务 /portrait/batch P1

导入（上传→预检查→执行→状态/错误明细）、导出（筛选/字段/格式/加密）。
