## 3. 四系统回灌接入架构（DT-11-01）

### 3.1 接入模式

```
┌──────────────┐     适配层（兼容层）     ┌──────────────────┐
│  四系统       │ ◄──── 旧 API 别名/字段映射 ────► │  openbase 底座    │
│ OpenLLM      │                              │  auth/tenant/     │
│ OpenRAG      │ 灰度替换（audit/otel →      │  config/mcp/      │
│ OpenMemory   │ auth/tenant/config/mcp）    │  audit/otel/      │
│ DPS          │                              │  errors           │
└──────────────┘                              └──────────────────┘
```

### 3.2 灰度替换顺序（RT-102~105）

| 阶段 | 环境 | 替换模块 | 验证 |
|------|------|---------|------|
| Dev | OpenLLM | audit/otel（低风险） | 单测+集成 |
| Test | OpenRAG/OpenMemory | config/mcp/tenant/observability | E2E+多租户回归 |
| Pro | DPS + 全量 | errors 对齐 + 全部 | 上线检查+监控 |

### 3.3 兼容层设计

- 旧 API 别名：四系统旧函数/类名保留为别名（deprecated 标记），指向 openbase 实现
- 字段映射：旧字段名 → openbase 标准字段（配置驱动映射表）
- 回滚：任一阶段失败 git revert + 旧实现 Git 历史保留

## 6. OTLP 告警通道（DT-11-04）

```
openbase 服务 ──OTLP──► OTLP Collector ──► Langfuse/Prometheus
                                                │
                                                ▼
                                          告警规则（P99>500ms P1 / 401率>20% P1）
```

| 项 | 设计 |
|----|------|
| 协议 | OTLP（observability 模块已埋点） |
| 告警规则 | P99>500ms（5min）P1；401 率>20%（5min）P1（对齐 v1.0.0 可观测性设计） |
| Dashboard | 6 个标准 Dashboard（Service/Resource/Dependencies/Business/Errors/Alert） |
| 依赖 | OTLP Collector 可用性（风险 R-103） |

## 7. 多实例 SSE（DT-11-05）

```
实例 A 发布 ──► Redis pub（openbase:notify:user:{id}）──► 实例 B 订阅 → SSE 推送
```

| 项 | 设计 |
|----|------|
| 发布 | notify 创建时 Redis pub（v1.0.6 已实现广播） |
| 订阅 | 实例启动时订阅 channel，收到消息转本地队列推送 |
| 回退 | Redis 不可用时本地队列直推（单实例） |
| 连接管理 | 订阅者注册/注销、心跳、断线重连 |

## 8. PyPI 发布链路（DT-11-06）

| 步骤 | 内容 |
|------|------|
| 1 | 构建（python -m build） |

| 3 | 发布（twine upload） |
| 4 | 验证（pip install openbase + import） |
| 依赖 | PyPI 账号（风险 R-103） |

## 9. Pro 部署架构（DT-11-07）

| 项 | 设计 |
|----|------|
| 策略 | 蓝绿（优先）或金丝雀（10%→50%→100%） |
| 环境 | 生产库 + 生产 Redis + 独立端口 |
| 上线检查 | health/login/核心 API + 监控告警 |
| 回滚 | 蓝绿流量切换 <30s；金丝雀阶段流量切回 |
| 必启约束 | openbase 先行启动（登录依赖） |
