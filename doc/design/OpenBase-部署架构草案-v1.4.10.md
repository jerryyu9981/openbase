## 1. 部署拓扑（Dev 目标环境）

```text
Dev 环境（本版目标）
├── openbase（应用服务）        ← 本版落点：dps_proxy 路由扩展（10 端点）
├── openbase-ui（静态构建产物）  ← dist-v1.4.10
├── DPS v2.11.x（同机）        ← 上游；cd DPS\src; python -m uvicorn main:app
├── OpenLLM（同机）            ← AI 复核辅助通道（经本仓 llm_proxy）
└── 共享基础设施（.env.shared-infra）← PostgreSQL ／ Redis
```

| 项 | 设计 |
|----|------|
| 目标环境 | **Dev**（Test／Pro 另行排期，与 v1.4.8／v1.4.9 同口径） |
| 进程形态 | 单进程 uvicorn（沿用 v1.4.9 部署形态） |
| 部署方式 | **直接部署**（Dev 环境，复用既有流程） |
| 端口 | 沿用既有分配（本版**不新增端口**） |

## 2. 环境与配置

| 环境 | 用途 | 本版要求 |
|:----:|------|----------|
| **Dev** | 开发自测与联调 | ✅ **本版目标**；须配 `dps_org_map`／`dps_code_map` |
| Test | 独立测试 | ⬜ 另行排期（本版不部署） |
| Pro | 生产 | ⬜ 另行排期 |

### 2.1 配置项清单（**本版关键**）

| 配置 | 作用 | 默认 | 本版要求 |
|------|------|------|----------|
| `DPS_ORG_MAP`（或 `DPS_CODE_MAP`） | org 别名 → **真实 org 值** | **空（未配）** | ⚠ **必须配**（否则 DPS 401／归属校验失败） |
| `DPS_TENANT_MAP` | tenant 值映射 | 空 | 按需（与 org 配套） |
| `DPS_DEFAULT_ORG_ID`／`DPS_DEFAULT_TENANT_ID` | 兜底（**已 deprecated**） | 空 | 不建议使用（改用映射表） |
| **`ENFORCE_ORG_ALIAS`** | 别名强模式 | **`False`** | ⚠ **必须保持 False**（True 时强制 `org == tenant`，与传真 org **互斥**） |

> **配置来源**：`settings.dps_code_map_entries()` ＋ `dps_org_map`／`dps_tenant_map`（见 `dps_proxy/__init__.py:96-113`）。
> **实测现状（2026-09-29）**：`.env` 中**上述 6 个键全部缺失** ⇒ 别名为空表回落 ⇒ **列为 P1 联调前置**。

## 3. 依赖与就绪顺序

```text
① 共享基础设施（PostgreSQL／Redis）就绪
      ↓
② DPS 服务启动并可访问（health OK）      ← 本机已验证（D3）
      ↓
③ openbase 启动（加载配置：映射表 ＋ enforce_org_alias=False）
      ↓
④ openbase-ui 静态产物发布（dist-v1.4.10）
      ↓
⑤ 联调验证（10 端点 ＋ AI 复核链路）
```

| 依赖 | 就绪判据 | 状态 |
|------|----------|:----:|
| PostgreSQL／Redis | 连接成功 | 沿用 |
| **DPS** | `/health` → healthy | ✅ **已验证**（v2.11.1） |
| **OpenLLM** | `/openllm/v1/health` 或模型列表可用 | ⏳ 联调时验证 |
| 联调账号（具 `portrait_template:*`／`annotation_template:*`） | 可完成写操作 | ⏳ **前置待办**（R11） |

## 5. 回滚方案（草案）

| 项 | 设计 |
|----|------|
| **首选** | **配置回滚**（若故障源于映射/开关配置 ⇒ 改配置重启，无需回退代码） |
| 代码回滚 | 回退至上一 tag（`v1.4.9`）＋ 重新部署 |
| 前端回滚 | 替换静态产物至 `dist-v1.4.9` |
| **DB 回滚** | **不需要**（本版**无 DB 迁移／无 schema 变更**） |
| 回滚演练 | Step 5 执行（沿用 v1.4.9 演练口径） |
| 判定阈值 | 10 端点批量 5xx／隔离失效／凭据泄露迹象 ⇒ **立即回滚** |

## 6. 部署风险

| # | 风险 | 级别 | 缓解 |
|:-:|------|:----:|------|
| 1 | `dps_org_map` 未配 ⇒ 401／归属校验失败 | **P1** | 部署前配置检查（列入发布入场检查） |
| 2 | 误开 `enforce_org_alias` ⇒ org≠tenant 403 | **P1** | 配置审查（双人确认） |
| 3 | DPS 侧 org／tenant 记录未预置 | **P1** | 与 #1 同批前置 |
| 4 | 联调账号未就绪 ⇒ 写操作不可验 | P2 | R11；未就绪时以只读路径先行 |
| 5 | `llm_proxy`→OpenLLM 链路未实测 | P2 | 联调验证；不可用则降级辅助 |
