## 1. 安全边界与资产

| 资产 | 分级 | 说明 |
|------|:----:|------|
| **模板配置**（模板族／版本／维度权重） | **内部** | 影响画像计算口径；写操作需权限门禁 |
| **标签与血缘** | 内部 | 反查能力可推断数据结构 |
| **标注（含 AI 候选）** | **内部（受门禁）** | **未复核候选不得进入标签/画像路径**（409 门禁） |
| **画像数据**（`person_id` 维度） | **受控** | 按租户隔离；本版**不新增**画像数据暴露面 |
| **身份凭据**（服务密钥、令牌） | **机密** | 前端零接触；日志零落盘 |
| **租户/组织标识** | 内部 | `X-Org-ID`／`X-Tenant-ID`；见 §4 |

**边界声明**：本版**不新增**数据存储实体（无 schema 变更）、**不新增**对外端点类型（仅代理既有上游端点）、**不引入**新信任边界。

## 2. 威胁建模（STRIDE 简版）

| 威胁 | 场景 | 现有控制 | 本版增补 |
|------|------|----------|----------|
| **S**poofing（伪造） | 前端伪造身份头直连 DPS 越权 | 身份头**仅由本仓 proxy 注入**；前端零密钥；DPS 侧 `IdentityGate` **fail-closed** | **不新增头**；文档明确「前端不可伪造」（PS-02） |
| **T**ampering（篡改） | 篡改导入包内容写入非法模板 | DPS 侧**白名单字段校验** → 422；`package_hash` 幂等 | 前端**不改包内容**（原样透传）；导入须显式选模式 |
| **R**epudiation（抵赖） | 回滚/导入后否认操作 | DPS 侧 `audit_logs`（org_id／tenant_id／user_id／action） | 前端二次确认 ＋ **依赖后端审计留痕**（本版不新增审计通道） |
| **I**nformation Disclosure（泄露） | 跨租户读取他人模板/画像；凭据落日志 | 租户隔离（`tenant_code`）；日志脱敏要求 | **隔离呈现**（空／403，PS-04）；**零凭据**（§5） |
| **D**enial of Service（拒绝） | 大包导入／高频反查 | 上游限流与超时 | 前端**不做重试风暴**（失败明确提示，不自动重试） |
| **E**levation of Privilege（提权） | 越权执行回滚/导入 | 权限点映射（`create`／`update`）；**前端不判定权限** | **映射口径已固化**（§3） |

## 3. 授权设计（DT-02）

| 端点族 | 权限点 | 动作来源 |
|--------|--------|----------|
| 导出／导入 | `portrait_template:create` | 需求 §7 明示（**非**方法默认） |
| **回滚** | `portrait_template:update` | 需求 §7 明示；DPS 端点级动作声明落地 |
| 对比／预检／建议／评分类型 | `portrait_template:read` | HTTP 方法映射 |
| 血缘反查／影响面 | `annotation_template:read` | HTTP 方法映射 |
| AI 候选生成 | `annotation_template:create` | HTTP 方法映射 |

**设计原则**：① **本仓不自行判定权限**（仅注入身份 ＋ 透传 403）；② **不新增权限点**（复用 `portrait_template:*`／`annotation_template:*`）；③ 403 呈现为业务语义而非系统错误。

## 4. 身份与租户安全（DT-02／DT-20）

| 项 | 设计 | 依据 |
|----|------|------|
| 出站头 | 四头 ＋ `X-Proxy-Source=dps` ＋ `X-Request-Id` | `dps_proxy:96-113` |
| **单键隔离** | `tenant_code` 为唯一隔离维度，**不新增隔离键** | 基准 B1 |
| org 语义 | `X-Org-ID` 为 tenant 的**可映射别名**（OB-8） | 基准 B2 |
| **强制约束** | **`enforce_org_alias` 必须 `False`**（True 时强制 `org == tenant`） | `inject.py:198-208` |
| 值映射 | 经 `dps_org_map`／`dps_code_map` 传真真实 org（**不硬编码**） | 架构 §4.2 |
| 跨租户呈现 | **空**或 **403**（无 500／无白屏） | NFR-04 |
| **P1 联调前置** | 映射未配 ⇒ DPS 401／归属校验失败 | 核对报告 §4-#1 |

## 5. 数据保护与日志

| 项 | 要求 | 落地 |
|----|------|------|
| 凭据零落盘 | 日志／响应／前端**不得出现**服务密钥、令牌、密码 | 沿用；Step 3 检索验证 |
| 前端零密钥 | 前端不持有任何上游密钥（经本仓代理） | 架构 ADR-01 |
| 日志最小化 | 不记录完整请求体；`request_id` 串链 | 沿用 `AGENTS.md` §6 |
| 敏感字段 | 沿用既有 `SENSITIVE_FIELD_KEYS` 禁落清单（各系统一致口径） | 跨系统核对报告 §2.3 |
| 错误信息 | 5xx **保留上游语义但不含凭据**；4xx message 原样（上游已保证可读性） | API 文档 §2 |

## 6. 输入校验

| 输入面 | 校验 | 责任方 |
|--------|------|--------|
| 路径参数（`{code}`／`{tag_code}`／`{adapter_id}`） | 基础非空校验（前端）；**语义以 DPS 为准** | 前端轻校验 ＋ 上游 |
| 查询参数（三层影响面维度） | 枚举校验（三选一）；`field_key` **显式不支持 → 400** | 前端 ＋ 上游 |
| 导入包 | **白名单字段校验 → 422**（上游） | **DPS**（前端不改包内容） |
| 回滚请求 | `target_version` 存在性 → 404 | 上游 |

**原则**：**前端不做权威校验**（避免与上游口径分叉）；仅做体验级前置校验。

## 7. 安全验收要点（→ Step 4）

| # | 断言 | 方式 |
|:-:|------|------|
| 1 | 前端**零密钥**接触 | 代码检索 |
| 2 | 跨租户/跨组织 → 空或 403（**无 500**） | E2E 隔离回归 |
| 3 | 无权限写操作 → **403** 呈现（前端不判定） | E2E |
| 4 | **未复核候选进入下游 → 409** 门禁生效 | 契约用例 |
| 5 | 导入非法包 → **422**（白名单） | 契约用例 |
| 6 | 日志零凭据 | 日志抽查 |
| 7 | `enforce_org_alias` 配置为 **False** | 配置审查 |
