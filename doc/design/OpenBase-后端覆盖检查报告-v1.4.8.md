## 4. 业务状态机：回写状态机（WritebackStore）

```text
                 ┌──────────────┐
     提交回写 ──▶ │   pending    │ ──受理：可观测────────────────────────────┐
                 └──────┬───────┘                                            │
                        │ 入库判定                                            │
                 ┌──────┴───────┐                                            │
                 ▼              ▼                                            │
           ┌─────────┐   ┌──────────┐    ┌─────────┐
           │ accepted│   │duplicated│    │ failed  │
           └─────────┘   └──────────┘    └─────────┘
                                               │ 退避重试 ≤3
                                               ▼
                                        (达到上限仍失败则终态 failed)
```

| 维度 | 覆盖 |
|------|------|
| 状态定义 | pending / accepted / duplicated / failed | ✅ |
| 初始状态 | pending（提交受理） | ✅ |
| 终止状态 | accepted / duplicated（成功）/ failed（达重试上限） | ✅ |
| 正常转换 | pending → accepted；pending → duplicated（幂等键命中） | ✅ |
| 异常转换 | pending → failed（失败）→ 重试（退避 ≤3）；组件不可用 → degraded 不报错 | ✅ |
| 超时处理 | 失败注入不影响主链路（AC-148-05-3） | ✅ |
| 并发冲突 | `max_seq+1` 防重（并发写同一会话不冲突） | ✅ |

**P0 状态机：正常路径 100%、异常分支 100% 覆盖** ✅
