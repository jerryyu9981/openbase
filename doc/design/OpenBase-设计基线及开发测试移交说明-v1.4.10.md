## 3. 开发移交要点（→ Step 3）

### 3.1 实现顺序建议（按 Phase）

| Phase | 内容 | 依赖 |
|:-----:|------|------|
| **P1** | `dps_proxy` 10 条路由 ＋ 权限映射（**先用桩／只读验证**） | 配置（§4） |
| **P2** | 只读页面（P-01／P-03／P-05／P-06／P-07） | P1 ＋ DPS 可用 |
| **P3** | 写操作页面（P-02 回滚／P-04 导入／P-08 复核） | P2 ＋ 联调账号 |
| **P4** | mock 真实化（BL-10）＋ 跨仓还债回填 | — |
| **P5** | 门禁收口（单测／E2E／覆盖率／隔离回归） | 全部 |

### 3.2 必须遵守的设计约束（**不得偏离**）

| # | 约束 | 依据 |
|:-:|------|------|
| 1 | **路由注册顺序**：静态段先于 `/templates/{code}/*`；包端点独立前缀 | 架构 §2.2 |
| 2 | **4xx/5xx 语义原样透传**，不转 500 | ADR-02 |
| 3 | **前端零密钥、零身份头构造、不做权限判定** | 安全 §3／§5 |
| 4 | **`enforce_org_alias` 必须 `False`** | ADR-04 |
| 5 | **不新增隔离键**（`tenant_code` 单键） | 基准 B1 |
| 6 | **不改 DPS 仓代码**（契约完备）；如需则可直接实施（记变更） | D-1410-02 |
| 7 | **不改设计系统／`tokens.css`** | 规划 §2.2 |
| 8 | **不引入新依赖** | ADR-05 |
| 9 | **原型一致性**：照搬 `--ob-*` 变量 ＋ Element Plus 视觉 ＋ `AppLayout` 布局，页面落点 `openbase-ui/src/modules/portrait/pages/`（命名 `Dps*View.vue`） | UI §1.1／前端架构 §6 |

### 3.3 编码必须覆盖的关键点（易漏）

| # | 关键点 | 依据 |
|:-:|--------|------|
| 1 | 回滚**二次确认四要素**（禁止一键直执行） | UI §4.1 |
| 2 | **导入模式不得默认实做**；dry-run 与实做视觉可区分 | UI §4.3 |
| 3 | `basis` 折叠气泡（`aria-expanded`）＋ **`tag_count=0` 强制展开** | ADR-06／UI §4.2 |
| 4 | P-08 **关闭态零写入** ＋ **三分支降级**（403／503／`llm_proxy` 不可用） | API §3.2／UI §4.4 |
| 5 | **409 双语义区分**（未复核门禁 vs code 冲突） | 契约对齐 §4 |
| 6 | 5xx **不静默降级**（明确提示 ＋ 重试） | NFR-06 |
| 7 | **DPS 模块范围内无 mock 常量** | DT-13／AC-13 |
