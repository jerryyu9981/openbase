## 1. 环境拓扑

| 环境 | 数据库 | Redis | 端口 | 部署方式 |
|------|--------|-------|------|---------|
| Dev | PG 192.168.0.151:5432/nuct | 192.168.0.151:6380 | 8765 | 源码直接部署 |
| Test | 同 Dev（独立验证） | 同 Dev | 8766 | 源码/容器 |
| Pro | 生产 PG | 生产 Redis | 8765 | 蓝绿/金丝雀 |

## 2. Pro 蓝绿部署设计

```
Blue（v1.0.0，运行中）──┐
                        ├── 负载均衡器（流量切换 <30s）
Green（v1.1.0，新发布）──┘
```

| 步骤 | 操作 |
|------|------|
| 1 | Green 部署 v1.1.0（新实例） |
| 2 | Green 冒烟（health/login/核心 API） |
| 3 | 流量切至 Green |
| 4 | 监控 15min（错误率/P99） |
| 5 | 异常 → 切回 Blue（<30s） |

## 3. 金丝雀部署设计

| 阶段 | 流量 | 监控 | 回滚 |
|------|------|------|------|
| 1 | 10% → v1.1.0 | 5-10min 指标正常 | 切回 100% v1.0.0 |
| 2 | 50% → v1.1.0 | 5-10min | 同左 |
| 3 | 100% → v1.1.0 | 上线检查 | 蓝绿切换回退 |

## 4. 环境变量与配置

| 变量 | Dev/Test | Pro |
|------|----------|-----|
| OPENBASE_DB_URL | 192.168.0.151 共享库 | 生产库（独立） |
| OPENBASE_REDIS_URL | 192.168.0.151:6380 | 生产 Redis |
| OPENBASE_JWT_SECRET | dev-secret | 生产密钥（配置中心） |
| OPENBASE_MCP_API_KEYS | dev-mcp-key | 生产 Key |

**密钥管理**：生产密钥经配置中心/环境变量下发，不入库不进 git（.env* 已 gitignore）。

## 5. 发布与回滚

| 项 | 设计 |
|----|------|
| 制品 | PyPI 包（pip install openbase）+ git tag |
| 回滚 | 蓝绿流量切回 / 金丝雀切回 / git revert |
| 数据库 | 幂等迁移（无破坏性变更） |
| 监控 | 健康检查 + OTLP 指标 + 告警规则（P99>500ms P1） |
