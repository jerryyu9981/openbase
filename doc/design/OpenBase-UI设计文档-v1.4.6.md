## 4. 交互状态清单（E2E 断言基线）

> 本清单为 Step 4 E2E 的断言依据（对齐 `prototype-coverage` 五态要求）。

| 状态 | 触发条件 | 预期表现 | 断言用途 |
|------|----------|----------|----------|
| **加载态** | 首次进入 / 切换筛选 / 切换数据源 | 表格区骨架或 `v-loading` 遮罩；分类导航计数显示占位 | E2E 加载指示断言 |
| **空态（无数据）** | 时间窗内该源确无记录（`total=0` 且无筛选条件） | "该时间段暂无日志" + 时间窗快捷入口 | E2E 空列表断言 |
| **空态（条件未命中）** | `total=0` 但存在筛选条件 | "无匹配结果" + **一键清空筛选**按钮 | E2E 空列表断言（区分两类） |
| **错误态** | 请求失败（401/403/503/500） | 错误卡片显示 `code` + `message` + `request_id`（可复制）+ 重试按钮 | E2E 错误提示断言 |
| **截断态** | `truncated=true` | 顶部黄色提示条：说明上限与收窄建议；**不阻断**数据展示 | E2E 截断提示断言（AC-146-04-3） |
| **成功态（导出）** | 点击导出并返回文件 | 触发浏览器下载；成功后 `el-message` 提示"已导出 N 条"；超限时提示"命中 X 条超过上限 10000，请收窄条件" | E2E 导出断言（AC-146-06-2） |
| **表单/筛选提交态** | 分类点选 / 关键字回车 / 时间窗变更 | 立即触发查询（无需显式提交按钮）；分类点选即过滤，导航项显示选中态（■） | E2E 交互断言 |
| **数据源切换态** | 切换数据源 | **保留**关键字与时间窗、**清空**分类选择并显式提示"已切换数据源，分类已重置" | E2E 交互断言（需求 §5.2） |

**子状态补充**：单源不可用 → 表格内空 + 顶部红色提示 `SYS_503`（含 `source` 与 `request_id`）。

## 9. 统一前端归属矩阵（路径级，v1.1.0 新增）

> **本节回应需求评估报告 §6#1（归属矩阵补齐路径列）**。需求 §10.6 的矩阵以**页面/组件名**为粒度；本节定义**路径级**的落地口径与生成方式。

### 9.1 生成方式（禁止人工转写）

**不手工誊写路径**。路径级矩阵由**脚本从路由表提取**并生成：

| 步骤 | 做法 |
|:----:|------|
| 1 | 从 `core/router/index.ts`（静态路由）+ 各 `modules/*/index.ts`（模块路由）**程序化提取**：`path` / `name` / `component` / `meta.permission` |
| 2 | 与需求 §10.6 的**组件名**做**一对一关联**（组件路径 → 页面标识） |
| 3 | 输出「现路径 → 目标归属（域/模块）→ 目标路径 → 重定向来源」四列表 |
| 4 | 差异核对：路由表条数 vs 矩阵条数，**差异 0 或显式登记**（AC-146-11-2） |

**理由**：60+ 页面的路径人工转写必然引入错漏；脚本化可复跑、可回归，且与 AC-146-11-2「清单 vs 路由表差异 0」的验证方式天然一致。

### 9.2 平台管理四域目标路径方案（已定义）

| 域 | 目标前缀 | 归类示例 |
|----|---------|---------|
| 身份与权限 | `/platform/identity/**` | 用户 / 团队 / 组织 / 租户 / 角色权限 / 工作空间 / 认证扩展 |
| 平台配置与密钥 | `/platform/config/**` | 全局配置 / **模块开关** / API 密钥 |
| 可观测与审计 | `/platform/observability/**` | **日志中心** / 测试记录 / 监控 / 链路 / GPU / 用量 / 成本预算 / 告警 / 计费 / 服务发现与编排 |
| 开发者资源 | `/platform/developers/**` | 文档中心 / EdgeRouter 与适配器 / 接入指南 / 插件 |
| 个人与帮助 | `/personal/**` | 个人设置 |

### 9.3 `GenericPage` 多路由复用的处理规则（需求评估报告 §6#1 专项）

实测 `openllm` 模块以 `GenericPage.vue` **一个组件承载多个路由**（提供商注册 / 模型部署 / GPU 资源 / EdgeRouter 适配器 / 调用记录 / 链路追踪 / 预算 等）。

| 规则 | 说明 |
|------|------|
| R1 | `GenericPage` **不整体迁移**；按**被承载的路由**逐条判定归属（同一组件可能**部分留模块、部分上收**） |
| R2 | 迁移后若某路由的目标域组件仍为 `GenericPage`，**允许保留**（复用既有实现），但须在 §9.1 输出表中**逐路由登记**目标路径与域 |
| R3 | 禁止把 `GenericPage` 整个文件复制到 `pages/platform/**` 造成**双份实现**（避免后续演进分叉） |
| R4 | 若同一路由的目标域与源域不同，须在**重定向映射表**中登记该路由 |
