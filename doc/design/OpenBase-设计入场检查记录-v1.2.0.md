## 2. 轨道选择确认

| 轨道 | 状态 | 依据 |
|------|------|------|
| 整体 🎯 | 激活（永恒） | 系统架构/非功能/部署整体设计 |
| 后端 ⚙️ | 激活（永恒） | 统一鉴权契约对接、OpenAPI 客户端、AI 应用新 API、四系统代理 |
| 前端 🎨 | 激活 | v1.2.0 核心为统一前端（底座/动态模块/四特色模块/响应式），全栈项目强制原型 |
| 第三方集成 🔗 | 激活 | 四系统（OpenLLM/OpenRAG/OpenMemory/DPS）特色 API 对接 |

**轨道一经确定本版本内不得增减。**

## 3. 设计输入摘要

| 输入 | 说明 |
|------|------|
| 前端底座抽取 | 从四系统前端抽取组件/布局（技术栈盘点见系统架构文档 §4 ADR） |
| 动态模块 | 4 特色模块经注册表挂载，懒加载 + 权限控制 |
| 统一鉴权 | JWT 登录/刷新 + ErrorResponse 契约 + OpenAPI 客户端生成 |
| OpenLLM 特色模块 | 大模型接入管理/AI 应用（全新补建）/对话监控/平台联动，板块分类与布局由本阶段重设计（用户指示） |
| 响应式 | 三断点（≥1280 / 768-1280 / <768），栅格/侧边栏折叠/表格横滚/图表自适应 |
