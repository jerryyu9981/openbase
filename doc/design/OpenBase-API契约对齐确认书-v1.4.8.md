## 1. 对齐范围

本版本前端**无页面新增/改造**（需求 §8 声明）；前端变化仅限 openbase-ui 发消息时**提交会话标识**（`llm.ts:101/113`，接口层配合）。因此前端页面清单 ↔ 后端 API 对齐聚焦于「消息发送」数据流。

---

## 2. 前端页面清单 ↔ 后端 API 对齐表

| 前端页面 / 调用点 | 前端数据需求 | 后端 API | 对齐结论 |
|-------------------|--------------|----------|:--------:|
| 会话消息发送（`llm.ts` 发消息） | 提交 `{model, messages, session_id}` | `/chat`、`/chat/stream`（`OpenLLMChatRequest`） | ✅ 一致 |
| 会话标识 | 前端会话生命周期维护，可选提交 | `session_id`（可选）缺省→按用户 | ✅ 一致 |
| 历史 messages | 已随 messages 提交（无需改造 | `messages` 数组入上下文（get_context_window 截取） | ✅ 一致 |
| 会话响应展示 | 响应/流式 SSE 事件 | 响应结构不变；两路径一致性 ⼒ | ✅ 一致 |

---

## 3. 交叉验证（前端 ↔ 后端 ↔ 跨仓契约）

| 对齐维度 | 检查内容 | 结果 |
|----------|----------|:----:|
| 前端所需字段 ⊆ 后端提供 | 前端仅需 `session_id` 提交，后端契约已定义（可选） | ✅ 无遗漏 |
| 后端返回字段是否全被前端使用 | 计量/回写回执为服务端观测/服务端查询面，无前端 UI 使用（`internalFlag` 类冗余不存在） | ✅ 无冗余冲突 |
| 枚举/状态映射一致性 | 前端无会话状态枚举展示；回写状态（accepted/duplicated/failed）为服务端观测面 | ✅ 一致 |
| 跨仓契约敏感字段 | openbase-ui 会话标识不携带凭据；禁记敏感字段（v1.4.6 契约口径） | ✅ 一致 |
