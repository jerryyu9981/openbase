## 1. 设计目标

在 97 号文“分类管理 + 考核奖惩”基础上，吸收三份新附件的六维标签体系与两张详细标注模板，形成可直接落库的：

1. **9 个子模板**：基础信息、行为表现、风险评估、教育帮扶、矫正进展、特殊属性 + 分类管理、考核、奖惩。
2. **8 个标注模板**：在上述 3 个业务标注之外，新增行为表现、教育帮扶、心理特征、特殊属性标注。
3. **标签字典**：约 110 项，覆盖六维标签、心理特征、教育帮扶与业务规则。
4. **个性化矫正方案映射**：标签识别 → 需求定位 → 措施匹配 → 效果评估。
5. **动态调整机制**：月度看执行、季度看风险、事件触发即更新。

## 4. 主模板评分

| 维度 | 权重 | 评分口径 |
|---|---|---|
| 基础信息 | 10 | 完整率 ×100（关键字段缺失按项扣减） |
| 行为表现 | 20 | 合规率 ×100；定位异常/缺席/违规按次扣分 |
| 风险评估 | 15 | 低 100/中 70/高 40；心理危机“紧急”直接 0 并触发干预 |
| 教育帮扶 | 20 | 四类帮扶达标数：4 类 100、3 类 85、2 类 70、<2 类 50 |
| 矫正进展 | 15 | 考核结论 + 方案执行率 + 趋势（0.4/0.4/0.2） |
| 特殊属性 | 5 | 专项措施落实率 ×100 |
| 考核 | 10 | 合格 100/不合格 40；特殊管理只记录不计分 |
| 奖惩 | 5 | 基础 100；训诫 -15、警告 -30、治安 -50、表扬 +10，归一 |

综合分 = Σ（维度分 × 权重）/100；等级 A ≥85、B 70–84、C 55–69、D <55（建议值，可配置）。

| 三级审核 | 心理专员→司法所→县级 | object | 审核重点：工具适用性、与日常记录一致性、风险与干预匹配 |
| 数据来源 | 测评报告/辅导台账/情绪观察日志 | array | 填写具体编号 |

### 5.3 其余标注模板

- **分类管理**：类别、依据、审批层级、特殊情形与期限、八项措施、证据。
- **考核**：周期、扣分明细（19 项）、累计分、审批权限、结论与不合格原因、考核日期。
- **奖惩**：类型、触发条件、次数、决定机关/日期、公示、异议、撤销原因。
- **行为表现**：报告频次执行、定位异常、教育缺席、违规级别、外出与变更报告。
- **风险**：风险等级/类型、再犯风险、心理危机、脱管天数、特殊管理与复核。
- **特殊属性**：未成年分开考核/不公示、病残孕与三无帮扶、变更执行地、生物核验。

## 9. 口径冲突与处置

| 附件表述 | 97 号原文/标准 | 处置 |
|---|---|---|
| 集体教育 2 次/月（普通）、3 次/月（严格/特殊），引用“第23条” | 第八/九/十条：集体教育每月至少 1 次；第23条为表扬条件 | 以 97 号原文为基线；2/3 次作为可配置地方加严标准，需业务确认；纠正条款引用 |
| 线上教育 4/6 小时/月 | 97 号未规定 | 作为地方补充指标，默认关闭或按地市开关 |

| 职业技能培训引用“第24条” | 第24条为训诫情形 | 纠正为“帮扶扩展”，不引用具体条款 |
| 社会救助/就业指导引用 SF/T 0081 第8.1.6条 | 属技术规范建议 | 保留为参考依据，需民政/人社数据核验 |
| 矫正对象 ID 20 位格式 | 地方平台编码规则 | 作为业务主键映射，DPS 内部仍用 `person_id`，外部 ID 存 `external_id` |
