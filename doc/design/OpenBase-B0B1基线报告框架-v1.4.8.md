## 1. 报告定位

B0/B1 基线报告是「更精准」「更省 token」的**可证伪依据**：

* **B0**：第零段后、前置零前测量，**严格只观测**；本身测不出改善，以相邻点位差值为辅。
* **B1**：第一批后测量，证明 P1（会话轴）与 P3（回写接齐）在 B0→B1 的差值。

**D3 未确认期间**：本条挂起并保留测量入口；不得以「无基线数据」规避硬判据（重启后回写丢失数=0、两路径行为一致）。

## 2. 报告要素清单（AC-148-07-2/3 报告要素核查）

| 要素 | 定义 |
|------|------|
| 方法 | 采样方法、测量时点、口径 |
| 样本量 | 各场景条数 / 判定模型采样 ≥30 条 |
| 漏检率区间 | 归因 B 校准得到的漏检率置信区间 |
| WCR 三分口径 | 硬浪费 / 软占用 / 必要占用（三者之和=1），不得只给单值 |
| 判定方法三要素 | A 引用检测（纵向对比）+ B LLM 归因 + C 消融 |

## 3. 工装与判定设计（对齐派选 §5.3、统一方案 §16.4）

### 3.1 工装就绪（随 RT-148-01 交付，无条件部分）

* 工装 1~7（Prompt 组成计量 / 检索快照 / 回执落库 / 归因 A / 归因 B 工具 / 固定集与评分表 / 汇总脚本）。
* 计量字段可按 `request_id` + 会话标识批量导出（AC-148-01-1）。

### 3.2 判定方法三层递进

| 层 | 方法 | 频次 | 解读约束 |
|:--:|------|------|----------|
| A | 引用检测（n-gram / 关键词） | 每次调用（主指标） | **只能纵向对比，不得作绝对值解读** |
| B | LLM 归因（抽样） | ≥30 条/轮 | 校准漏检率；判定模型不与被评模型同源 |
| C | 消融（一次性） | 10~15 条 | 效度检验 |

### 3.3 固定集与评分表（工装 6）

* **7 场景矩阵**（含 2 组负例），每场景 ≥5 条，共 ≥35 条（统一方案 §16.4.4）。
* 四维 1~5 分量表；固定 `temperature=0`。
* 盲评；≥20% 样本间隔 ≥24h 复评，算自一致性。
* 记录：评分人 / 日期 / 模型版本 / 问题集版本。

### 3.4 判定规则（AC-148-07 相关）

| 情形 | 判定 |
|------|------|
| token 降但评分明显降 | **判失败**（以精准换 token） |
| 评分升但 token 显著升 | 须预算利用率仍有余量且超窗率 = 0 |
| 指标未变 | 须说明原因 |
| 数据不足 | 记「不可判定」须重测 |
