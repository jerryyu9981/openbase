## 1. 部署形态（v1.3.0）

```
Dev 环境（本次验收）
┌────────────────────────────────────────────────┐
│ openbase-ui（Vite dev / 静态资源）               │
│  → /api/v1/proxy/{system}/* 代理请求            │
├────────────────────────────────────────────────┤
│ openbase 后端（uvicorn :8000）                  │
│  auth / users / roles / services / proxy        │
│  [v1.3.0] 402 错误码（BIZ_MODEL_QUOTA）         │
├────────────────────────────────────────────────┤
│ PostgreSQL + Redis（底座依赖）                  │
└────────────────────────────────────────────────┘

四系统实例（对接挂起，按需启动）
  OpenLLM :8001 ｜ OpenRAG :8010 ｜ OpenMemory :8020 ｜ DPS :8030
```

## 2. 环境与端口

| 环境 | openbase-ui | openbase 后端 | 依赖 | 说明 |
|------|------------|--------------|------|------|
| Dev | 5173（Vite） | 8000 | PG + Redis | 基座调试验收环境 |
| Test | 静态部署 | 8000 | PG + Redis | 后续 |
| Pro | 静态部署 | 8000 | PG + Redis | 后续 |

## 3. 配置项

| 配置 | 说明 |
|------|------|
| `proxy.{system}.base_url` | 四系统代理目标（默认 8001/8010/8020/8030，config 模块键） |
| `MOCK_FLAG`（前端构建） | 四系统模块 mock/真实切换（VC-005 对接挂起） |
| 402 映射 | 错误码表 BIZ_MODEL_QUOTA（HTTP 402） |

## 4. 发布与回滚

| 项 | 内容 |
|----|------|
| 发布 | 前端静态资源（含 30 页组件）+ 后端 proxy/402 增量；静态资源灰度 10%→50%→100% |
| 回滚 | 静态资源版本回退；后端 git revert（proxy 增量可单独回退） |
| 验收 | Dev 基座联调验收（登录/鉴权/RBAC/动态模块 E2E）通过后发布 |
