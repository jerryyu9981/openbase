## 2. 画像列表页设计

| 项 | 内容 |
|----|------|
| 布局 | 工具栏（搜索 + 刷新）+ 表格（姓名/标签/风险等级/更新时间/操作）+ 分页 + KPI 卡（画像总数/标签数/风险预警） |
| 交互 | 行点击/详情按钮 → 跳转详情页；搜索前端过滤；分页 |
| 状态 | 加载态（表格 loading）/ 空态（"暂无画像"）/ 错误态（el-alert + 重试按钮） |
| 数据映射 | 上游 items → 表格行（person_id/name/tags/risk_level/updated_at） |

## 3. 画像详情页设计

| 项 | 内容 |
|----|------|
| 布局 | 头部（姓名/ID/风险等级 tag）+ 画像维度区（六维数据展示：基础/行为/偏好/风险/社交/设备）+ 标签区 + 关联信息 |
| 交互 | 标签展示（el-tag）；风险等级色标（低=success/中=warning/高=danger） |
| 状态 | 加载态/空态（"暂无画像数据"）/ 错误态（el-alert + 重试） |
| 数据映射 | 上游 detail → 维度字段（dimensions）、tags、risk_level |

## 4. 交互状态清单（原型状态断言基线）

| 状态 | 画像列表页 | 画像详情页 | E2E 断言 |
|:-----|:----------|:----------|:---------|
| 空态 | 空表格 + "暂无画像" | "暂无画像数据" | 空列表元素断言 |
| 错误态 | 错误提示 + 重试按钮 | 错误提示 + 重试按钮 | 错误提示断言 |
| 加载态 | 表格 loading | 内容区 loading | loading 断言 |
| 成功态 | 真实数据渲染 | 维度/标签渲染 | 数据行断言 |
