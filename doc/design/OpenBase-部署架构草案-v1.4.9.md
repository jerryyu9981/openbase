## 1. 部署形态

| 项 | 设计 |
|----|------|
| 制品 | 本仓 Python 框架（无新增独立服务） |
| 拓扑 | 不变（既有进程内模块 + 既有网关链路） |
| 环境 | Dev（本版本闭环环境）／Test／Pro —— **本次仅规划，Test/Pro 执行属环境前置** |
| 依赖 | 无新增外部中间件；无 schema 迁移 |

## 2. 配置与开关

| 配置 | 默认 | 说明 |
|------|:----:|------|
| 裁剪与计量总开关 | **关闭** | 关闭时行为与 v1.4.8 逐字一致 |
| 输出预留 / 安全余量 | 随实现给出默认值 | 可配置；回执登记实际取值 |
| 计量与回执 | 随总开关 | 建议灰度时**先开计量**（零风险）再开裁剪 |

## 3. 灰度与回退

| 步骤 | 动作 | 观察 |
|:----:|------|------|
| ① | 开计量与回执（不裁剪） | 回执覆盖率 100%、无行为变化 |
| ② | 按租户/场景开裁剪 | 超窗率 = 0、WCR 与评分（D3 就绪时） |
| ③ | 全量 | 回归全通过 |
| 回退 | **关闭开关**（不发版） | 立即回到不裁剪行为；第三批写入治理可单独回退 |

## 4. 发布门禁（沿用规划文档 §7）

① 四件套经人工批准；② **超窗率 = 0** 实测通过；③ 评分不低于 B1（D3 就绪时）；④ 三项阈值已回填或已按过渡口径声明；⑤ 本仓回归全通过。
