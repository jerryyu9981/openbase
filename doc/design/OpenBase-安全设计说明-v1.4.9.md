## 1. 威胁建模（STRIDE 精简）

| 威胁 | 场景 | 缓解 |
|------|------|------|
| 信息泄露 | 回执可能携带片段/回答正文 → 泄露业务内容 | 回执字段**白名单**，仅计量与标识；**正文不落库**（SEC-149-01） |
| 信息泄露 | 掩码失效导致令牌进入回执 | 沿用 `AC-148-01-5`；敏感串扫描用例断言（AC-149-11） |
| 篡改 | 裁剪开关被越权开启（影响全部租户） | 开关变更属**变更动作**，需显式声明环境并由负责人控制（SEC-149-02） |
| 越权/数据隔离 | 写入治理绕过租户过滤 | 治理逻辑**不得**绕过既有 tenant 过滤（SEC-149-03） |
| 拒绝服务 | 超长素材导致装配耗时激增 | 预算与截断**有界**；保险丝为硬截断（§3.6） |

## 2. 回执字段白名单（与 API §2 对应）

**允许**：模型标识、窗口/预留/余量/预算、裁剪前后 token、被丢弃片段的 `source/id/reason`、硬截断标记、降级标记、开关状态。
**禁止**：片段正文、回答正文、请求体全文、令牌、密钥、密钥派生信息、个人信息。

## 3. 权限与租户

| 项 | 设计 |
|----|------|
| 裁剪开关 | 默认关闭；开启需显式配置（环境级），变更留痕 |
| 写入治理 | `save_if_valuable=false` ⇒ 不写入；判定服务不可用时**保守不写入** |
| 多租户 | 回执与回写均带 tenant 维度，过滤不放松 |
| 审计 | 开关状态写入回执（`enabled`）⇒ 可事后归因 |
