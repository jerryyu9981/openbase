## 版本摘要

本版本完成统一前端全量补全（30 页功能 + 租户管理）与基座后端联调，四系统（OpenLLM/OpenRAG/OpenMemory/DPS）与后端 API 对接按 VC-005 挂起分批，前端按契约 mock 先行。

## 新增功能

| 模块 | 内容 |
|------|------|
| 基座 | 租户管理页面（列表/创建/配额/启停/删除）+ 402 错误码（BIZ_MODEL_QUOTA）统一处理 |
| OpenLLM | 模型中心 14 项：提供商 CRUD、模型 CRUD+定价、本地模型、注册/找回、个人设置、用量统计、我的收藏、分类/对比、对话管理、监控仪表盘、API 密钥、告警、成本预算、路由/熔断 |
| OpenRAG | 5 项：RAG 对话（流式+来源引用）、知识库列表、详情、用户管理、系统配置 |
| OpenMemory | 5 项：记忆图谱（d3 力导向）、会话记忆、详情、API 网关、管理后台 |
| DPS | 6 项：画像列表、详情、查询、标签、数据总览、规则引擎 |

## 关键变更

- 依赖：新增 d3 ^7.9.0 + @types/d3（ADR-13-03 知识图谱选型）
- 配置：vite preview.proxy（/api → 8000，对应生产 Nginx 反代）
- 后端：`BIZ_MODEL_QUOTA`(402) 错误码 + 代理层 402 统一包装（不暴露上游原始错误）
