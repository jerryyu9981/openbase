## 1. 申请背景

豁免行加固代码与本地预演已完成（OpenLLM `8d20a27` / v2.19.1），剩余 L-1~L-4 的生产闭环必须在目标环境执行：

- **L-1**：下发生产 `.env` 并验证「不合规拒绝启动」
- **L-2**：生成/下发 metrics token，配置 Prometheus Bearer 抓取
- **L-3**：同步 OpenMemory 监听整改，导出网络控制证据
- **L-4**：K07 矩阵终验与门禁回放

上述操作涉及生产配置、密钥、监控与网络策略，需申请**限时、最小范围**的访问权限。

## 4. 安全约束

1. **双人在场**：配置写入与密钥操作由执行人完成，复核人核对长度/前缀与结果，不接触明文。
2. **先备份后变更**：`.env`、Prometheus 配置、防火墙规则变更前必须备份并记录校验和。
3. **最小暴露**：仅开放 8001（OpenLLM）与 8020（OpenMemory）的必要来源；禁止 `0.0.0.0`。
4. **禁止共享库写入**：反例探针必须使用独立 SQLite 与独立端口，禁止连接生产数据库。
5. **证据脱敏**：证据中不得包含 token、密码、完整 `.env`、个人隐私数据。
6. **时限回收**：窗口结束 30 分钟内回收临时权限，撤销密钥管理写权限与防火墙写权限。
7. **审计留痕**：所有命令、变更前后 diff、审批记录归档至 `doc/test/evidence/s7/security/exempt-hardening/window-<YYYYMMDD>/`。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|------|:----:|------|
| 配置错误导致服务不可用 | 中 | 变更前备份 + 正例/反例验证 + 回滚包就绪 |
| token 泄露 | 高 | 密钥管理下发、禁止明文、窗口后轮换 |
| 防火墙误封业务 | 中 | 仅改 8001/8020 入站，变更前后连通性验证 |
| 探针误连生产库 | 高 | 强制 `DATABASE_URL=sqlite:///./probe.db` + 独立端口 |
| 权限超期 | 中 | 申请单标注时限，窗口结束强制回收并复核 |
| 证据不完整导致无法双签 | 中 | 按执行包 P8 清单逐项核对后离场 |
