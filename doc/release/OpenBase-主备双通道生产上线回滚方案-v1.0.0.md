## 1. 目标与原则

- **目标**：以**最小动作、最短时间**将主备双通道回退到「可服务且不劣化」的状态，且**不破坏既有单租户路径**。
- **原则**：① 优先**开关级**回退（可逆、秒级）；② 通道回退以**通道裁决单一事实源**（`channel_report`）为准，不手工改状态；③ 版本级回退沿用各仓既有回滚方案；④ **回退即失去对应门禁保护**，须同步评估安全影响。

## 2. 触发条件

| 级别 | 触发情形 |
|:----:|---------|
| L1 | 生产开关置真后出现：组件级持续不可用、错误率超阈值、配额/租户判定大面积 403 |
| L2 | 主通道 B 劣化（LLM 不可达或组件降级持续）→ 需或需撤销接管 |
| L3 | 版本升级引入不可接受的回归（参照各仓回滚方案判据） |

## 3. 回滚分级

| 级别 | 对象 | 动作 | 可逆性 | 影响面 |
|:----:|------|------|:------:|--------|
| **L1** | **开关级**：`OPENLLM_*_REAL` / `*_ENABLED` / 生产门禁 5 组 / `CHANNEL_AUDIT_ENABLED` | 在目标环境 `.env` 将对应开关置回**上线前值**并重启 | 高（改回即可） | ⚠ 门禁置假 ⇒ **失去生产门禁保护**（须评估） |
| **L2** | **通道级**：主通道 designation（B/A）、`bypass_orchestration` | 由 `channel_report` 单一事实源驱动复位（**不手工改内存态**） | 高 | 仅影响通道选择；写路径随 T11 恢复/暂停 |
| **L3** | **版本级**：OpenLLM（主通道编排与回写）等 | 回退到上线前版本（沿用各仓《回滚方案》） | 中 | 需逐仓评估数据面（本方案不新增结构变更 ⇒ 纯代码回滚） |

## 4. 回滚步骤

### 4.1 L1 开关级（首选）

1. 备份当前 `.env`（**不入库**；`.env` 被 `.gitignore` 排除）；
2. 将 `OPENLLM_OPENMEMORY_REAL` / `OPENLLM_OPENRAG_REAL` / `OPENLLM_DPS_REAL`（及 `OPENMEMORY_ENABLED` / `OPENRAG_ENABLED` / `DPS_ENABLED`）置回上线前值；
3. 如需同时回退门禁：置回 5 组（`ENFORCE_INBOUND_IDENTITY_HEADERS` / `TENANT_SCOPE_ENFORCE` / `TENANT_HEADER_CONSISTENCY_ENFORCE` / `QUOTA_MISSING_FAIL_CLOSED` / `RBAC_PERMISSION_ENFORCE`）；
4. 经受管编排入口重启：`scripts/service-orchestrator.ps1 -Action stop|start -Only openllm`；
5. 验证（见 §5）。

### 4.2 L2 通道级

1. 读取 `GET /openllm/v1/health` → `channel` 段落，确认真实态（`primary_channel` / `healthy_b` / `degraded_dimensions`）；
2. 若为「LLM 不可达」触发的自动接管：恢复 LLM 可达后**由裁决逻辑自动复位**（不手工改）；
3. 若为「演练接管」手工置 A：按演练脚本的反向步骤复位；
4. 验证写路径恢复（T11）：回写由 `skipped` 恢复为正常执行。

### 4.3 L3 版本级

沿用 OpenLLM/各仓既有《回滚方案》；因本批**不新增数据面结构变更**（仅 `.env.example` 模板与文档），**纯代码/配置回滚**，无迁移回退。

## 5. 验证判据（回滚后须全绿）

| # | 判据 | 通过标准 |
|:-:|------|---------|
| V1 | 启动健康 | `ENV=production` 配置下应用**正常启动**；`/openllm/v1/health` 三组件与 `channel` 段落可读 |
| V2 | 通道正确 | `channel_report`：主通道符合回退目标（B 或 A）；`bypass_orchestration` 符合决策规则 |
| V3 | 写路径一致 | 回退到 B 时回写正常；回退到 A 时回写 `skipped`（T11） |
| V4 | 既有路径零变化 | 单租户/存量路径行为与上线前**逐字一致**；无新增 4xx/5xx |
| V5 | 证据留档 | 回滚记录（时间/操作人/开关前后值/`/health` 快照）落档 |

## 6. 演练要求

- 上线前（或联调窗口）按 §4 完成 **L1 与 L2 各一次演练**并留证；
- 演练须在**受控窗口**、经**受管编排入口**执行，**禁裸 `Stop-Process`**（沿用编排唯一入口纪律）。

## 7. 风险与边界

1. **门禁回退即失去保护**：L1 中回退生产门禁会使应用在配置不合规下可启动 ⇒ 仅限故障止损，须同步评估并尽快恢复；
2. **不手工改通道内存态**：一切以 `channel_report` 单一事实源为准，避免「观测与决策分离」被破坏；
3. **`.env` 不入库**：回滚动作须**人工同步**至其他环境（沿用既定纪律）；
4. 本方案**不含**数据面结构回退（本批无结构变更）；若后续引入迁移，须另附数据回退步骤。
