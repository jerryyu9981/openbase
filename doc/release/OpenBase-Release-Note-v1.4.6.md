## 1. 版本概述

**平台可观测性 + 日志域收官 + IA 治理**（VC-012 / VC-013 / VC-014 三源合流）：本版本聚焦「日志中心（分类查看与检索）」+「统一前端功能布局重构」+「四仓日志接入（本仓侧）」三大部分——

- **日志中心（R-382）**：新增三源统一查询接口（L1 结构化日志 / `audit_logs` 审计库 / 测试记录）＋四仓日志适配器，四维分类浏览（模块/操作类型/结果/操作人），关键字与多条件检索、时间窗与分页，测试三元组检索，CSV/JSON 导出（含 `log.export` 留痕），权限码 `log:read`（管理员跨租户），服务端脱敏，前端统一日志中心页 `/system/logs`。
- **统一前端 IA 重构（R-383）**：顶层导航「三分」（仪表盘 / 业务模块 / 平台管理），平台管理四域归并（身份与权限 / 平台配置与密钥 / 可观测与审计 / 开发者资源），系统性能力上收（模块内管理·监控·权限·设置·密钥·用量类页迁入平台域），全局页目录边界治理，路由兼容重定向与权限菜单一致性。
- **四仓日志接入（R-384，本仓侧适配器）**：`repo_log` 适配器 + 字段映射脱敏（默认关闭采集 / 强制脱敏 / 单条上限 2KB / 开关留痕），评审权限 `module:manage` 生效滞后 `next_login`。四仓 7 文件改动由各仓独立评审与发布，本版本仅交付 OpenBase 侧适配器与契约。

|----|------|
