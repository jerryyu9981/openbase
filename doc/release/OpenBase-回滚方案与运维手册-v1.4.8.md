## 3. 运维手册（要点）

| 场景 | 处置 |
|------|------|
| 服务不可用 | 查进程/端口 → 看结构化日志 `request_id` → 必要时按 §1 回滚 |
| 上游（OpenLLM/DPS/OpenRAG/OpenMemory）不可达 | 代理按设计**如实返回 502 `SYS_502`**（不伪造成功）；检查上游健康与网络 |
| 回写积压 | 查回写队列表 `stats`（`GET /api/v1/llm-proxy/...` 或回执接口）→ 死信重放 → 必要时暂停投递 |
| 配置变更 | 走配置中心（含变更日志）；新增观测开关默认关闭，开启需显式声明环境 |
| 排障命令（示例） | `python -m pytest tests/test_llm_proxy.py -q`；`git log --oneline -5`；`python -c "import openbase"` |
| 联系人 / SLA | 项目内（PM/DO/AU）；Dev 无 SLA 承诺 ⇒ 生产 SLA 待环境与运维约定后确定 |
